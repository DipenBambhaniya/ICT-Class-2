How the topics connect

Layering sets the mental model everything else fits into. Ethernet and Wi-Fi provide the Data Link/Physical foundation; flow & error control and switching keep data moving reliably and efficiently across links and nodes. IP addressing and routing move packets across networks end to end; TCP/UDP then deliver that data to the right process, with congestion control keeping the shared network stable. Application protocols ride on top, and network security (authentication, cryptography, firewalls) protects the whole stack.
