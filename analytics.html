How the topics connect

The analytics maturity model (descriptive → predictive) sets the goal; OLAP and the OLTP/OLAP distinction explain the workload split needed to get there. Data cubes and dimensional schemas (star/snowflake/constellation) are how a data warehouse physically organizes data for that analysis. Data mining supplies the techniques that power predictive/prescriptive work, while in-database analytics and advanced SQL are the practical tools that make all of it executable.
