How the topics connect

Hardware sets the stage; the OS abstracts it. A process is the unit of resource ownership, a thread the unit of scheduling. IPC and synchronisation let concurrent activities cooperate — and deadlock is what goes wrong when they wait on each other. CPU scheduling divides time; virtual memory divides space; the file system provides durable named storage.
