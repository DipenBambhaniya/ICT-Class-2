Data Mining Techniques

Data mining discovers patterns, relationships, and knowledge from large datasets using statistical/ML techniques — the concrete tools that power predictive and prescriptive analytics.

Key points

Classification (supervised)
Assigns records to predefined categories using labeled training data (e.g. loan default: yes/no). Decision trees are a common, interpretable technique.
Clustering (unsupervised)
Groups similar records with NO predefined labels (e.g. customer segmentation). K-means is the classic algorithm; the analyst chooses k.
Association rule mining
Discovers frequent co-occurrences ("market basket analysis"). Key metrics: support (frequency), confidence (conditional probability), lift (strength beyond chance).
Regression (supervised)
Predicts a CONTINUOUS numeric value (vs. classification's discrete category).
Evaluation
Confusion matrix, precision (of predicted positives, % actually positive), recall (of actual positives, % caught), and the precision/recall trade-off. Guard against overfitting via train/test splits.

Example

Association rule metrics, "bread -> butter":

Transactions total: 1000
Contain bread: 200        Contain both bread & butter: 120
Contain butter: 300

Support(bread,butter)  = 120/1000        = 0.12  (12% of all transactions)
Confidence(bread->butter) = 120/200      = 0.60  (60% of bread buyers also buy butter)
Lift = Confidence / P(butter) = 0.60 / (300/1000) = 0.60/0.30 = 2.0
  -> Lift > 1: buying bread makes buying butter TWICE as likely
     compared to baseline -- a genuinely useful association.
Common exam traps

Classification predicts a CATEGORY (discrete); regression predicts a NUMBER (continuous) — don't mix them up. Clustering needs NO labels; classification/regression DO. Lift > 1 means positive association; lift = 1 means no real relationship (independence). High accuracy can be misleading on imbalanced data — precision/recall matter more there.

Practice MCQs

Q1. Classification is used to:

  1. Group records with no predefined categories
  2. Assign records to predefined categories using labeled training data
  3. Discover frequent item combinations
  4. Reduce the number of dimensions
Show answer

Answer: B. A supervised learning technique.

Q2. Clustering is used to:

  1. Assign records to predefined categories
  2. Group similar records with NO predefined class labels
  3. Predict a continuous numeric value
  4. Only work on time-series data
Show answer

Answer: B. Unsupervised — e.g. customer segmentation.

Q3. "Confidence" in association rule mining measures:

  1. Overall itemset frequency
  2. P(B|A) — the likelihood of B given A
  3. The number of clusters
  4. Regression fit quality
Show answer

Answer: B. Assesses a rule's reliability.

Q4. Overfitting means a model:

  1. Is too simple to capture any pattern
  2. Fits training data too closely and performs poorly on new data
  3. Always performs equally well on training and new data
  4. Is unrelated to predictive modeling
Show answer

Answer: B. Guarded against via train/test splits and cross-validation.

Q5. "Recall" as a classification metric measures:

  1. Of all actual positives, the % correctly identified
  2. Overall accuracy across all predictions
  3. A clustering quality measure
  4. The association rule confidence metric
Show answer

Answer: A. High recall means few missed (false negative) cases.
