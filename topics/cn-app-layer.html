Application Layer Protocols

DNS, SMTP, POP/IMAP, FTP and HTTP each solve one user-facing task — naming, email, file transfer, web content — and each has a characteristic default port and transport-layer choice worth memorizing.

Key points

DNS
Translates domain names to IPs. Hierarchical (root → TLD → authoritative). UDP port 53 (TCP for large responses/zone transfers). Record types: A, AAAA, MX, CNAME, NS.
SMTP / POP3 / IMAP
SMTP sends/relays outgoing mail. POP3 downloads and typically deletes from the server. IMAP keeps mail synced on the server across devices.
FTP
Two TCP connections: control (port 21) and data (port 20 in active mode). Plaintext by default — FTPS/SFTP add encryption.
HTTP / HTTPS
Request/response, stateless (cookies add state). Port 80 (HTTP) / 443 (HTTPS, TLS-encrypted). GET retrieves; POST submits. Status codes: 2xx success, 3xx redirect, 4xx client error, 5xx server error.
Ports to memorize
DNS 53, HTTP 80, HTTPS 443, FTP 20/21, SSH 22, SMTP 25, POP3 110, IMAP 143.

Example

A minimal HTTP request/response:

Client -> GET /index.html HTTP/1.1
          Host: www.example.com
          Accept: text/html

Server -> HTTP/1.1 200 OK
          Content-Type: text/html
          Content-Length: 1256

          <html>...</html>

If the page had moved: HTTP/1.1 301 Moved Permanently
If it didn't exist:    HTTP/1.1 404 Not Found
Common exam traps

HTTP default port is 80, HTTPS is 443 (not the reverse). POP3 = download (often delete); IMAP = keep synced on server. FTP uses TWO TCP connections. SMTP is for SENDING mail, not retrieving it. GET appends parameters in the URL; POST puts data in the request body. DNS is typically UDP, not TCP, for ordinary queries.

Practice MCQs

Q1. DNS primarily provides the service of:

  1. Encrypting web traffic
  2. Translating domain names into IP addresses
  3. Transferring files
  4. Sending email
Show answer

Answer: B. A distributed, hierarchical naming system.

Q2. SMTP is used for:

  1. Retrieving email from a mailbox
  2. Sending/relaying email
  3. Browsing the web
  4. Resolving domain names
Show answer

Answer: B. Retrieval uses POP3 or IMAP instead.

Q3. Compared to POP3, IMAP generally:

  1. Always deletes mail after download
  2. Keeps mail on the server, synced across devices
  3. Cannot retrieve email
  4. Uses the same port as SMTP
Show answer

Answer: B. This is why IMAP suits users checking mail from multiple devices.

Q4. The standard TCP port for unencrypted HTTP is:

  1. 21
  2. 25
  3. 80
  4. 443
Show answer

Answer: C. 443 is for HTTPS.

Q5. HTTP status code 404 means:

  1. Server error
  2. Not Found
  3. Success
  4. Redirect
Show answer

Answer: B. The requested resource doesn't exist at that URL.
