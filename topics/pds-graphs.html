Graphs

A graph G=(V,E) models arbitrary pairwise relationships — directed or undirected, weighted or not. Representation and traversal choice drive the complexity of every graph algorithm.

Key points

Representations
Adjacency list O(V+E) space (good for sparse); adjacency matrix O(V²) space, O(1) edge lookup (good for dense).
BFS
Queue; unit-weight shortest paths; O(V+E).
DFS
Stack / recursion; cycle detection, topological sort, SCCs, bridges; O(V+E).
Shortest paths
BFS (unweighted), Dijkstra (non-negative, O((V+E)log V)), Bellman-Ford (negative edges, O(VE)), Floyd-Warshall (all pairs, O(V³)).
MST
Kruskal (sort edges + union-find) and Prim (grow from a vertex with a heap); a spanning tree has V−1 edges.

Example

/* BFS: O(V + E) */
q.push(s); seen[s] = 1;
while (!q.empty()) {
    u = q.pop();
    for (v : adj[u]) if (!seen[v]) { seen[v] = 1; q.push(v); }
}

Common exam traps

Dijkstra fails with negative edges — use Bellman-Ford. Topological sort exists only for a DAG. An adjacency matrix costs O(V²) even for a sparse graph. In BFS, mark visited on enqueue. Deciding a Hamiltonian cycle is NP-complete; an Euler circuit test (all even degree) is polynomial.

Practice MCQs

Q1. An adjacency list uses how much space?

  1. O(V^2)
  2. O(V + E)
  3. O(E^2)
  4. O(V log E)
Show answer

Answer: B. One list per vertex; total length 2E (undirected).

Q2. BFS and DFS both run in:

  1. O(V^2)
  2. O(V + E) with an adjacency list
  3. O(E log V)
  4. O(V!)
Show answer

Answer: B. Each vertex and edge is processed a constant number of times.

Q3. Dijkstra's algorithm fails when the graph has:

  1. cycles
  2. negative-weight edges
  3. more than 1000 vertices
  4. disconnected components
Show answer

Answer: B. Its greedy finalize-closest step is invalid with negative edges.

Q4. Topological sort is defined for:

  1. any graph
  2. directed acyclic graphs only
  3. undirected connected graphs
  4. weighted graphs only
Show answer

Answer: B. A cycle makes a consistent linear order impossible.

Q5. A minimum spanning tree of a connected graph with V vertices has:

  1. V edges
  2. V - 1 edges
  3. E - V edges
  4. 2V edges
Show answer

Answer: B. A spanning tree connects all V vertices acyclically.
