Data Cubes

A data cube organizes measures across multiple dimensions into cells and "cuboids" — pre-aggregated views at different levels of detail — that OLAP operations navigate.

Key points

Cell / cuboid
A cell is the measure value at one specific combination of dimension values. A cuboid is a whole aggregation "layer"; a cube with n dimensions can have up to 2^n cuboids.
Base vs apex cuboid
Base = finest detail (no aggregation). Apex = grand total, every dimension collapsed to one summary value.
Materialization
Full (compute every cuboid — fast queries, high cost), partial (materialize only common ones), or none (compute on demand) — a storage/performance trade-off.
Measure additivity
Additive (sales — sums correctly everywhere), semi-additive (account balance — sums across accounts but not time), non-additive (a ratio — must be recomputed, not summed).
Iceberg cube
Only materializes cells meeting a minimum threshold, avoiding storage waste on tiny/insignificant combinations.

Diagram

Example

Base cuboid (finest detail): one row per (Product, Region, Day)
  Laptop, West, 2024-03-01: 12 units

Roll up to (Product, Region, Month):
  Laptop, West, 2024-03: 340 units   <- sums correctly (additive)

Roll up to (Region) only, all Products/Time collapsed = apex-ish:
  West: 8,120 units

Non-additive example: Profit Margin % must be recomputed as
  (sum of profit) / (sum of revenue) at each level --
  NOT averaged directly from lower-level margin percentages.
Common exam traps

A cube with n dimensions can have up to 2^n cuboids — not just n. The base cuboid is the FINEST detail, not the most aggregated. Additive measures (like sales) sum correctly at any level; semi-additive (like account balance) do NOT sum meaningfully across time; non-additive (like a ratio) must be recalculated, never simply summed or averaged.

Practice MCQs

Q1. A data cube's "cell" represents:

  1. A single database table
  2. The measure value for one specific combination of dimension values
  3. A dimension hierarchy level
  4. An index
Show answer

Answer: B. Every unique dimension-value intersection has a corresponding cell.

Q2. A cube with n dimensions can have up to how many cuboids?

  1. n
  2. 2^n
  3. n^2
  4. Exactly 1
Show answer

Answer: B. Each dimension can be included at some level or fully collapsed.

Q3. The base cuboid represents:

  1. The most aggregated, grand-total level
  2. The finest level of granularity, least aggregated
  3. A cuboid with no dimensions
  4. The average of all cuboids
Show answer

Answer: B. The starting point before any roll-up.

Q4. An "iceberg cube" is one that:

  1. Materializes every possible aggregate combination
  2. Only materializes cells meeting a minimum threshold
  3. Has no measures
  4. Is used only for ice cream sales data
Show answer

Answer: B. Reduces storage for sparse/insignificant combinations.

Q5. Account balance is an example of which type of measure?

  1. Fully additive across every dimension
  2. Semi-additive — sums across accounts but not meaningfully across time
  3. Non-additive, never summable
  4. Not a valid measure type
Show answer

Answer: B. Summing balances across 12 months doesn't give a meaningful year-end figure.
