Concept of Layering

Networking is organized into layers, each solving one part of the communication problem and offering a clean service to the layer above. The OSI model has 7 layers; the TCP/IP suite actually deployed on the Internet condenses this to 4-5.

Key points

OSI model (7 layers)
Physical, Data Link, Network, Transport, Session, Presentation, Application ("Please Do Not Throw Sausage Pizza Away").
TCP/IP model (4-5 layers)
Link, Internet (IP), Transport (TCP/UDP), Application — merges OSI's Session/Presentation/Application into one.
Encapsulation
Each layer wraps the data from above with its own header (sometimes a trailer) as it moves down the stack on the sender.
Decapsulation
The receiver strips headers off in reverse order as data moves up its stack.
PDU names
Bit (Physical) → Frame (Data Link) → Packet (Network) → Segment/Datagram (Transport).

Example

Browser sends an HTTP GET request:

Application  ->  "GET /index.html HTTP/1.1..."
Transport    ->  TCP header (src port 51000, dst port 80) + HTTP data
Network      ->  IP header (src 10.0.0.5, dst 93.184.216.34) + TCP segment
Data Link    ->  Ethernet header (src/dst MAC) + IP packet + FCS trailer
Physical     ->  bits on the wire / radio waves

The receiving web server reverses this exactly, peeling off
one header per layer as the data moves back up its stack.
Common exam traps

OSI has 7 layers; TCP/IP is usually taught as 4 or 5 (it folds Session + Presentation + Application together). A router works at Layer 3 (IP); a switch works at Layer 2 (MAC); a hub is pure Layer 1. "Encryption" is a function, not an OSI layer by itself — it is often associated with Presentation. Remember PDU names: frame → packet → segment, not interchangeable.

Practice MCQs

Q1. How many layers does the OSI model have?

  1. 4
  2. 7
  3. 5
  4. 9
Show answer

Answer: B. Physical, Data Link, Network, Transport, Session, Presentation, Application.

Q2. Which OSI layer handles routing between different networks?

  1. Data Link
  2. Network
  3. Transport
  4. Session
Show answer

Answer: B. The Network layer (IP) provides logical addressing and routing.

Q3. The Transport-layer PDU is called a:

  1. Frame
  2. Packet
  3. Segment (TCP) / Datagram (UDP)
  4. Bit
Show answer

Answer: C. Frame is Data Link, Packet is Network.

Q4. Encapsulation means:

  1. Removing all headers before sending
  2. Each layer adding its own header around the data from the layer above
  3. Compressing the payload
  4. Encrypting only the Application layer
Show answer

Answer: B. Headers are added going down the stack, then stripped in reverse (decapsulation) at the receiver.

Q5. The TCP/IP model condenses which three OSI layers into one "Application" layer?

  1. Physical, Data Link, Network
  2. Session, Presentation, Application
  3. Network, Transport, Session
  4. Only Presentation
Show answer

Answer: B. TCP/IP applications handle these concerns directly rather than via separate layers.
