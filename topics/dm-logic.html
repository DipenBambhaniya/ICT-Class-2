Logic (Propositional & First-Order)

Propositional logic combines true/false statements with connectives; first-order logic adds predicates, variables and quantifiers. The tools: truth tables, equivalences, inference rules, and validity vs satisfiability.

Key points

Connectives
~ (not), ∧ (and), ∨ (or), → (implies — false only when T→F), ↔ (iff — same truth value).
Key equivalences
p → q ≡ ~p ∨ q; contrapositive ~q → ~p ≡ p → q (converse q → p is NOT); De Morgan ~(p ∧ q) ≡ ~p ∨ ~q.
Inference
Modus ponens (p→q, p ⊢ q), modus tollens (p→q, ~q ⊢ ~p). Affirming the consequent and denying the antecedent are fallacies.
Tautology / SAT
Tautology = true under every assignment; a formula is valid iff its negation is unsatisfiable. SAT (is there a satisfying assignment?) is NP-complete.
Quantifiers
~(∀x P) ≡ ∃x ~P; ~(∃x P) ≡ ∀x ~P. Order matters: ∀x∃y ≠ ∃y∀x. FOL validity is only semi-decidable.

Example

Prove:  (p → q) ∧ ~q  ⊢  ~p   (modus tollens)
  1. p → q            premise
  2. ~q               premise
  3. ~q → ~p          contrapositive of 1
  4. ~p               modus ponens on 2, 3

Quantifier negation:
  ~( ∀x  Prime(x) → Odd(x) )   ≡   ∃x ( Prime(x) ∧ ~Odd(x) )   [witness: x = 2]
Common exam traps

The converse (q → p) is NOT equivalent to p → q; the contrapositive (~q → ~p) IS. 'If pigs fly then 2+2=4' is TRUE (false premise). ~(∀x P) is ∃x ~P, not ∀x ~P. Swapping ∀x∃y to ∃y∀x strengthens the claim. A valid argument can have false premises (it just isn't sound).

Practice MCQs

Q1. The implication p → q is FALSE only when:

  1. p is false
  2. p is true and q is false
  3. q is true
  4. both are true
Show answer

Answer: B. A true premise with a false conclusion.

Q2. The contrapositive of p → q is:

  1. q → p
  2. ~p → ~q
  3. ~q → ~p
  4. p → ~q
Show answer

Answer: C. Equivalent to the original; the converse is not.

Q3. p → q is logically equivalent to:

  1. ~p ∨ q
  2. p ∨ ~q
  3. ~p ∧ q
  4. q → p
Show answer

Answer: A. Material implication — used in CNF conversion.

Q4. ~(∀x P(x)) is equivalent to:

  1. ∀x ~P(x)
  2. ∃x ~P(x)
  3. ∃x P(x)
  4. ∀x P(x)
Show answer

Answer: B. One counterexample refutes a universal.

Q5. The Boolean satisfiability problem (SAT) is:

  1. in P
  2. NP-complete (Cook-Levin)
  3. undecidable
  4. trivial
Show answer

Answer: B. It was the first problem proven NP-complete.
