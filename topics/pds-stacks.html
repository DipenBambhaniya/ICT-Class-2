Stacks

A stack is a LIFO container: the last element pushed is the first popped. push, pop and peek are all O(1). It models nested/most-recent-first processing — function calls, undo, bracket matching, expression evaluation, DFS.

Key points

Operations
push (add to top), pop (remove top), peek/top (read top), isEmpty — all O(1).
Underflow / overflow
Pop from empty = underflow; push onto a full fixed array = overflow.
Implementations
Array with a top index, or a singly linked list pushing/popping at the head.
Expression forms
Infix needs precedence + parens; postfix (RPN) and prefix evaluate in one stack pass, no precedence rules.
Uses
Call stack, undo/redo, browser back, DFS, balanced parentheses, infix→postfix (shunting-yard).

Diagram

Example

/* Evaluate postfix: 2 3 + 4 *   */
push(2); push(3);
b = pop(); a = pop(); push(a + b);   /* → 5 */
push(4);
b = pop(); a = pop(); push(a * b);   /* → 20 */
result = pop();                      /* 20 */

/* Balanced parentheses: push opens, on a close pop & check match */
Common exam traps

Given push order 1,2,3 a stack can output 1,2,3 / 2,1,3 / 1,3,2 / 3,2,1 but not 3,1,2. Postfix/prefix need no parentheses. Converting tail recursion to iteration needs no explicit stack; general recursion does. 2PL (locking) ≠ stack.

Practice MCQs

Q1. A stack follows which principle?

  1. FIFO
  2. LIFO
  3. priority order
  4. random access
Show answer

Answer: B. Last In, First Out.

Q2. push and pop are:

  1. O(n)
  2. O(log n)
  3. O(1)
  4. O(n) for push only
Show answer

Answer: C. Both act only at the top.

Q3. Infix a + b * c in postfix is:

  1. a b c * +
  2. a b + c *
  3. + a * b c
  4. a b * c +
Show answer

Answer: A. * binds tighter: b c * first, then a (…) +.

Q4. Given push order 1,2,3, which output is impossible with a stack?

  1. 1,2,3
  2. 2,1,3
  3. 3,1,2
  4. 1,3,2
Show answer

Answer: C. To pop 3 first you must have pushed 1,2,3; then only 2 then 1 can follow.

Q5. Popping from an empty stack is:

  1. overflow
  2. underflow
  3. wrap-around
  4. a collision
Show answer

Answer: B. Underflow. Overflow is pushing onto a full fixed stack.
