Worst, Average & Best-Case Analysis

Worst case is a guarantee for every input; average case assumes an input distribution; best case is often a rare, misleading extreme. Randomized algorithms move the randomness into the algorithm itself.

Key points

Worst case
Upper bound holding for ALL inputs of size n — needed for real-time / hard deadlines.
Average case
E[T(n)] over an assumed input distribution (usually 'uniformly random').
Quicksort
Worst Θ(n²) (sorted input, bad pivot); average / expected Θ(n log n).
Randomized (expected) time
Over the algorithm's own coin flips — holds for EVERY fixed input.
Las Vegas vs Monte Carlo
Las Vegas: always correct, random time. Monte Carlo: fixed time, small error probability.

// Quicksort worst case: pivot = first element, input already sorted
[1,2,3,4,5] → pivot 1 → split 0 : 4 → pivot 2 → split 0 : 3 → ...
T(n) = T(n-1) + O(n) = O(n²)

// Fix: random pivot or median-of-three ⇒ expected O(n log n) for ANY input
Common exam traps

Merge sort's worst = average because it splits by index, not value. A schedule/algorithm can be 'O(n log n)' as a loose upper bound while its tight bound is Θ(n²) — say Θ. Randomized quicksort's worst case is still Θ(n²), but it occurs with negligible probability, so expected time is O(n log n) for every input.

Practice MCQs

Q1. Worst-case analysis gives:

  1. the typical running time
  2. an upper bound holding for EVERY input of size n
  3. the fastest possible time
  4. the average over random inputs
Show answer

Answer: B. It is a guarantee.

Q2. Quicksort worst / average time:

  1. n log n / n log n
  2. n^2 / n log n
  3. n^2 / n^2
  4. n log n / n^2
Show answer

Answer: B. Bad pivots on sorted data give O(n^2).

Q3. Merge sort's worst, average and best case are:

  1. O(n), O(n log n), O(n^2)
  2. all O(n log n)
  3. all O(n^2)
  4. all different
Show answer

Answer: B. It always splits in half and merges linearly.

Q4. Insertion sort: best (sorted) / worst (reverse):

  1. O(n) / O(n^2)
  2. O(n log n) / O(n^2)
  3. O(n) / O(n log n)
  4. O(1) / O(n)
Show answer

Answer: A. Sorted: one compare per element. Reverse: every element shifts fully.

Q5. A Las Vegas algorithm:

  1. may give a wrong answer
  2. always correct; running time is random
  3. fixed time, answer may be wrong
  4. never terminates
Show answer

Answer: B. Monte Carlo is the fixed-time, possibly-wrong kind.
