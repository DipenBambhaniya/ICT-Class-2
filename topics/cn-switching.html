Switching

Switching techniques describe how data moves through intermediate nodes from source to destination: reserve a dedicated path first (circuit), route each unit independently (packet/datagram), or something in between (virtual circuit).

Key points

Circuit switching
Dedicated end-to-end path reserved for the whole session (classic telephone network). Predictable bandwidth/delay, but wastes capacity during silence.
Packet (datagram) switching
Each packet is routed independently; no reservation. Statistically multiplexes bursty traffic efficiently — the Internet's IP layer works this way.
Virtual-circuit switching
A logical path is set up once (e.g. ATM, MPLS); packets carry a short circuit ID and follow that fixed path in order — a hybrid of the two extremes.
Message switching
Stores an entire message at each hop before forwarding — mostly of historical interest, superseded by packet switching's smaller units.
Store-and-forward vs cut-through
Store-and-forward waits for the whole frame (can check CRC); cut-through starts forwarding as soon as the destination address is read (lower latency, less safety).

Example

Same 3 packets of one "message", three switching styles:

Circuit switching:   [====== one dedicated path reserved ======]
                      P1 -> P2 -> P3   (fixed path, guaranteed capacity)

Virtual circuit:      VCI=42 set up once
                      P1(VCI42) -> P2(VCI42) -> P3(VCI42)  (same path, in order)

Datagram switching:   P1 via Router A -> C
                      P2 via Router A -> B -> C  (different path!)
                      P3 via Router A -> C
                      -> may arrive OUT OF ORDER; each hop decided independently
Common exam traps

IP is connectionless/datagram — packets can arrive out of order. A virtual circuit still shares physical bandwidth statistically; it is NOT the same as a dedicated physical circuit. ATM uses fixed 53-byte cells. Store-and-forward can check the FCS before forwarding; cut-through cannot. Message switching stores the WHOLE message per hop — that's why it's obsolete for practical networks.

Practice MCQs

Q1. Circuit switching works by:

  1. Breaking data into independently routed packets
  2. Establishing a dedicated end-to-end path before transfer begins, held for the whole session
  3. Storing entire messages at each node
  4. Broadcasting to all nodes
Show answer

Answer: B. Guarantees bandwidth but wastes capacity when idle.

Q2. Datagram (connectionless) packet switching means:

  1. All packets follow the same fixed path
  2. Each packet is routed independently and may arrive out of order
  3. A circuit is set up first
  4. Packets cannot be lost
Show answer

Answer: B. This is how IP works — higher layers handle reordering if needed.

Q3. Virtual-circuit switching uses a:

  1. Full destination address on every packet
  2. Short virtual circuit identifier (VCI) for the pre-established path
  3. Dedicated physical wire per session
  4. No addressing at all
Show answer

Answer: B. The VCI avoids a full routing decision at every hop.

Q4. Store-and-forward switching:

  1. Forwards each bit as it arrives
  2. Receives the whole frame, checks it, then forwards
  3. Never checks for errors
  4. Requires a virtual circuit
Show answer

Answer: B. Adds latency but allows CRC verification before forwarding.

Q5. ATM uses which fixed-size unit?

  1. Variable-length packets up to 1500 bytes
  2. Fixed-size 53-byte cells
  3. Whole messages
  4. 1-byte units
Show answer

Answer: B. 5-byte header + 48-byte payload, aiding predictable hardware switching.
