Algorithm Analysis

Algorithm analysis predicts how running time and memory grow with input size, independent of language and hardware, so you can compare designs before implementing them.

Key points

RAM model
Each simple operation (arithmetic, comparison, array access) costs 1 unit; analysis counts the dominant operation.
T(n)
The running-time function. Nested loops multiply; sequential blocks add; the highest-order term wins.
Recurrences
Recursive costs are expressed as T(n) = aT(n/b) + f(n); solved by the master theorem, recursion trees, or substitution.
Amortized analysis
Average cost per operation over a worst-case SEQUENCE (no probability) — e.g. dynamic-array append is amortized O(1).
Loop invariant
A property true before/after every iteration; used to prove correctness (initialization, maintenance, termination).

Example

for (i = 1; i <= n; i++)          // n iterations
    for (j = 1; j <= n; j++)      //   n iterations
        c[i][j] = a[i][j] + b[i][j];   // O(1)
// total = n · n · O(1) = Θ(n²)

for (i = 1; i <= n; i *= 2)  op();     // i doubles ⇒ Θ(log n) iterations
Common exam traps

A loop that multiplies the counter (i *= 2) runs O(log n) times, not O(n). 0 + 1 + 2 + … + (n-1) = Θ(n²). An algorithm 'linear in n' where n is a numeric input given in binary is actually exponential in the input's bit length (pseudo-polynomial).

Practice MCQs

Q1. The RAM model assumes each basic operation costs:

  1. variable time
  2. constant (unit) time
  3. O(log n)
  4. time proportional to operand size
Show answer

Answer: B. This machine-independence is what makes asymptotic analysis meaningful.

Q2. The loop for (i=1; i<=n; i*=2) runs how many times?

  1. n
  2. n/2
  3. log2 n
  4. sqrt n
Show answer

Answer: C. i doubles each step, reaching n after ~log2 n iterations.

Q3. for i in 1..n: for j in 1..i: op() runs:

  1. O(n)
  2. O(n log n)
  3. O(n^2)
  4. O(2^n)
Show answer

Answer: C. 1 + 2 + ... + n = n(n+1)/2 = O(n^2).

Q4. Amortized analysis gives:

  1. the single worst operation's cost
  2. the average cost per operation over a worst-case sequence
  3. the best case
  4. a probabilistic average
Show answer

Answer: B. No probability — it bounds the total over a sequence.

Q5. T(n) = T(n-1) + n, T(0) = 0 solves to:

  1. Theta(n)
  2. Theta(n log n)
  3. Theta(n^2)
  4. Theta(2^n)
Show answer

Answer: C. n + (n-1) + ... + 1 = n(n+1)/2.
