Data Security, Privacy & Protection

Data security protects data from unauthorized access; data privacy governs whether and how it's appropriately collected and used in the first place — "data protection" is the umbrella term covering both. The CIA triad (Confidentiality, Integrity, Availability) frames the core security goals.

Key points

CIA triad
Confidentiality (no unauthorized disclosure), Integrity (no unauthorized modification), Availability (accessible to authorized users when needed).
Security ≠ Privacy
Security = preventing unauthorized access/breach. Privacy = ensuring even AUTHORIZED collection/use respects individual rights and consent.
Anonymization vs pseudonymization
Anonymization is irreversible (no re-identification possible); pseudonymization replaces identifiers but remains re-identifiable with a separately held key.
Core principles
Data minimization (collect only what's needed), purpose limitation (don't repurpose without consent), least privilege access.
Encryption
At rest (stored data) vs in transit (data moving over a network) — both needed; a stolen encryption key defeats either.

Diagram

Example

A hospital handling patient records:
  Confidentiality: records encrypted at rest; role-based access control so
                    only a patient's own care team can view their chart
  Integrity:        digital signatures/checksums detect any unauthorized
                     edit to a diagnosis or prescription
  Availability:      redundant servers + tested backups ensure doctors can
                     access records even during a system outage

Privacy layer on top of security: the hospital collects only data needed
for care (minimization), gets patient consent before sharing data with a
research study (purpose limitation), and anonymizes records used in a
published study so individual patients can't be re-identified.
Common exam traps

Availability is about ACCESS when needed — a DoS attack is an availability violation, not confidentiality. Anonymized data must be irreversible; if it can be re-identified by combining datasets, it was only pseudonymized. Encryption is only as strong as its KEY MANAGEMENT — a leaked key defeats even strong encryption. Security and privacy are related but distinct: strong security with no consent for data use is still a privacy failure.

Practice MCQs

Q1. The CIA triad in information security stands for:

  1. Central Intelligence Agency (unrelated to security concepts)
  2. Confidentiality, Integrity, and Availability — the three core goals of information security
  3. Cybersecurity, Identity, and Authentication
  4. Compliance, Insurance, and Auditing
Show answer

Answer: B. These three properties are the foundational objectives most security controls aim to protect.

Q2. Data privacy, as distinct from data security, primarily concerns:

  1. Only the technical mechanisms used to prevent unauthorized data access
  2. The appropriate collection, use, and sharing of personal information in line with individuals' rights and expectations, complementing but distinct from the technical controls of data security
  3. Only encrypting network traffic
  4. A synonym for data security with no meaningful distinction
Show answer

Answer: B. Data security protects data from unauthorized access/breach; data privacy governs whether and how data should be collected/used in the first place.

Q3. Data anonymization involves:

  1. Encrypting data with a key that can later be used to decrypt it
  2. Irreversibly removing or altering personally identifiable information so individuals can no longer be identified from the data
  3. Simply renaming a file
  4. Backing up data to a secondary location
Show answer

Answer: B. Properly anonymized data cannot be re-linked back to a specific individual, unlike pseudonymized data.

Q4. Which scenario best illustrates a violation of the availability leg of the CIA triad?

  1. An unauthorized user reads confidential customer data
  2. A DDoS attack takes an organization's website offline for several hours
  3. Data is properly encrypted both at rest and in transit
  4. An audit log correctly records every data access
Show answer

Answer: B. Denial-of-service style disruptions specifically target the availability of systems/data to legitimate users.

Q5. The data minimization principle in data protection means:

  1. Collecting as much personal data as possible, just in case it's useful later
  2. Collecting and retaining only the personal data that is actually necessary for the specific, defined purpose
  3. Never collecting any data at all under any circumstances
  4. Only applies to financial data, not other personal data
Show answer

Answer: B. Data minimization reduces privacy risk and the potential impact of a future breach by limiting what data exists to be exposed.
