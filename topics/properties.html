Properties of NoSQL Databases

A set of recurring design properties — flexible schema, horizontal scale, distribution, the BASE consistency model — is what makes a database "NoSQL" in spirit, regardless of which data model it uses.

Feature map

BASE vs ACID

Where relational databases lean on ACID (Atomicity, Consistency, Isolation, Durability) for strict correctness, many NoSQL databases lean on BASE to favor availability and scale:

LetterMeansIn practice
BA — Basically AvailableThe system guarantees a response to every requestEven during failures, some node responds — possibly with older data
S — Soft stateState can change over time without new inputBecause replicas sync asynchronously, the observed value can drift until it settles
E — Eventual consistencyReplicas converge if no new writes occurGiven enough time, all copies end up agreeing

Core properties explained

🧩

Schema flexibility

Records can vary in shape; new fields don't require a database-wide migration.

📈

Horizontal scalability

Scale out by adding commodity servers instead of upgrading one machine.

✂️

Sharding

Large datasets are partitioned across nodes so no single server holds it all.

🔁

Replication

Copies of data live on multiple nodes, improving availability and durability.

🌐

Distributed architecture

Storage and query load spread across many networked nodes, not one machine.

🛡️

Fault tolerance

The system keeps serving requests even when individual nodes fail.

⚡

High performance (for the right pattern)

Denormalized data avoids costly joins, speeding up the specific access patterns it's designed for.

📦

Big data / unstructured support

Built to store and process structured, semi-structured, and unstructured data at volume.

Common exam trap

"Strict, cluster-wide ACID transactions for every operation" and "support for complex multi-table JOINs as a primary strength" are usually the wrong answer choices — these are relational-database strengths, not typical NoSQL properties.

Quick self-check

  • Can you expand the BASE acronym and explain each term?
  • Can you name three properties that let NoSQL scale horizontally?
  • Can you explain the trade-off NoSQL makes to gain high availability?
