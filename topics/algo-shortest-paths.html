Shortest Paths

Pick the algorithm by the weights: BFS (unweighted), Dijkstra (non-negative), Bellman-Ford (negative edges, detects negative cycles), Floyd-Warshall (all pairs), topological relaxation (DAG).

Key points

BFS
Unweighted single-source, O(V+E).
Dijkstra
Non-negative weights, O((V+E) log V) with a heap. Fails with negative edges.
Bellman-Ford
Relax all edges V−1 times, O(VE); a V-th improving pass ⇒ negative cycle.
Floyd-Warshall
All-pairs, O(V³) DP over intermediate vertices; negative edges OK, negative cycles detectable via dist[i][i] < 0.
Relaxation
if dist[u] + w(u,v) < dist[v]: update dist[v], set parent[v] = u.

Diagram

Example

// Dijkstra
dist[s] = 0; pq.push((0, s));
while (!pq.empty()) {
    (d, u) = pq.pop();
    if (d > dist[u]) continue;              // stale entry
    for ((v, w) : adj[u])
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w; parent[v] = u; pq.push((dist[v], v));
        }
}
Common exam traps

Dijkstra fails with negative edges even if it 'seems to work' on a given graph. Bellman-Ford needs exactly V−1 passes (a shortest path has ≤ V−1 edges). A shortest-path tree is not the MST. For a weighted DAG, relax in topological order — no heap, O(V+E), and negatives are fine.

Practice MCQs

Q1. Dijkstra's algorithm FAILS when the graph has:

  1. cycles
  2. negative-weight edges
  3. many vertices
  4. parallel edges
Show answer

Answer: B. A finalized vertex could be reached more cheaply via a negative edge.

Q2. Bellman-Ford runs in:

  1. O(V + E)
  2. O(V log V)
  3. O(V·E)
  4. O(V^3)
Show answer

Answer: C. It relaxes all E edges V-1 times.

Q3. For shortest paths in a weighted DAG:

  1. only Bellman-Ford works
  2. relax edges in topological order, O(V+E), negatives OK
  3. Dijkstra is required
  4. it is NP-hard
Show answer

Answer: B. Topological order finalizes each vertex before its out-edges.

Q4. Floyd-Warshall computes:

  1. single-source shortest paths
  2. all-pairs shortest paths in O(V^3)
  3. the MST
  4. maximum flow
Show answer

Answer: B. DP over allowed intermediate vertices.

Q5. The minimum Bellman-Ford passes needed for correctness (no negative cycle) is:

  1. 1
  2. V - 1
  3. V
  4. E
Show answer

Answer: B. A shortest path has at most V-1 edges.
