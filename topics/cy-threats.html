Threats, Vulnerabilities, Attacks & Ethical Hacking

Threat, vulnerability and attack are distinct terms often confused in exams. Malware, social engineering, DoS/DDoS/botnets and Wi-Fi-based attacks are the main offensive techniques — and ethical hacking (authorized penetration testing) is the defensive practice of finding these weaknesses before attackers do.

Key points

Threat vs vulnerability vs attack
Threat = potential danger. Vulnerability = exploitable weakness. Attack = the actual exploitation attempt.
Malware family
Virus (needs a host + user action), worm (self-spreading, no host needed), Trojan (disguised, doesn't self-replicate), ransomware (encrypts for ransom), spyware (covert monitoring).
Social engineering
Phishing/spear phishing/vishing/smishing, pretexting, baiting — manipulating people rather than exploiting code.
DoS · DDoS · Botnet
DoS floods a target from one source; DDoS floods it from many (often via a botnet of compromised "zombie" machines controlled by a C2 server).
Ethical hacking
Authorized pen testing (white/black/grey-box) following recon → scanning → gaining access → maintaining access → covering tracks, done legally to improve security.

Diagram

Example

An attacker builds a botnet, then launches a DDoS attack:
  1. Infect thousands of IoT devices with malware -> each becomes a "bot"
  2. Bots connect to the attacker's Command & Control (C2) server, awaiting orders
  3. C2 server instructs all bots to flood a target website with requests
     simultaneously (distributed = hard to block by source IP alone)
  4. Target's servers are overwhelmed -> legitimate users can't access it (DoS)

An ethical hacker, hired to test the SAME target beforehand, would instead:
  1. Get written authorization defining scope (black-box test)
  2. Reconnaissance -> scanning -> attempt controlled exploitation
  3. Report the DDoS-susceptibility finding, WITHOUT actually taking the site down
  4. Recommend mitigations (rate limiting, DDoS protection service, etc.)
Common exam traps

A virus needs a host file + user action; a worm self-replicates over a network with neither. DDoS = distributed (many sources, via a botnet); DoS = single source. White-box = full internal knowledge; black-box = none; grey-box = partial. Ethical hacking is defined by AUTHORIZATION, not by the techniques used (which mirror real attacks).

Practice MCQs

Q1. A computer worm, unlike a virus:

  1. Requires a host file to attach to and spread
  2. Self-replicates and spreads across networks without needing to attach to a host file or requiring user action
  3. Can only run on a single isolated machine with no network access
  4. Is a legitimate diagnostic tool
Show answer

Answer: B. Worms exploit network vulnerabilities to spread autonomously, unlike viruses which need a host and typically user action.

Q2. A DDoS (Distributed Denial of Service) attack, compared to a basic DoS attack:

  1. Originates from a single source, making it easy to block
  2. Is launched from multiple (often compromised) sources simultaneously, making it harder to block/mitigate than a single-source DoS
  3. Only targets email servers
  4. Cannot cause any service disruption
Show answer

Answer: B. The distributed nature of DDoS attacks makes simple IP-blocking defenses far less effective.

Q3. A botnet is:

  1. A single powerful attacker's personal computer
  2. A network of compromised computers ('bots' or 'zombies') controlled remotely by an attacker, often used to launch DDoS attacks or send spam
  3. A legitimate cloud computing service
  4. An antivirus scanning tool
Show answer

Answer: B. Botnets can comprise thousands to millions of infected devices, giving attackers massive coordinated attack capacity.

Q4. Ethical hacking refers to:

  1. Illegally breaking into systems for personal gain
  2. Authorized, legal attempts to find and exploit vulnerabilities in a system, with the owner's permission, to improve security
  3. A type of malware
  4. Only theoretical study with no actual system testing
Show answer

Answer: B. Explicit authorization is what distinguishes ethical hacking from illegal, malicious hacking.

Q5. A rogue/evil-twin Wi-Fi hotspot:

  1. Is a certified, secure access point provided by the venue
  2. Is a fake wireless access point set up to mimic a legitimate one, tricking users into connecting so the attacker can intercept their traffic
  3. Cannot be used to intercept any user data
  4. Always uses stronger encryption than a legitimate hotspot
Show answer

Answer: B. Evil-twin attacks exploit users' tendency to connect to familiar-sounding public Wi-Fi names without verification.
