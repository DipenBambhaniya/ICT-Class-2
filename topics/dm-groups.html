Groups

A group is a set with an associative operation, an identity, and inverses. Groups model symmetry and modular arithmetic; Lagrange's theorem, homomorphisms, cyclic groups and cosets are the essentials — with direct applications in cryptography.

Key points

Axioms
Closure, associativity, identity (unique), inverses (unique). Abelian adds commutativity. Semigroup = closure + assoc; monoid adds identity.
Order
|G| = number of elements. Order of an element a = smallest n with aⁿ = e. Lagrange: any subgroup's order (and any element's order) divides |G|.
Cyclic groups
Generated by one element. ℤ (infinite) and ℤ_n (order n) are the only ones up to isomorphism. ℤ_n has φ(n) generators.
Homomorphism & kernel
f(ab) = f(a)f(b). ker(f) = {g : f(g) = e} is a normal subgroup; f injective ⇔ ker(f) = {e}. First Isomorphism Theorem: G/ker(f) ≅ im(f).
Key theorems
(ℤ_n)* has order φ(n) ⇒ Euler's theorem a^φ(n) ≡ 1 (mod n) ⇒ RSA. Cayley: every group embeds in a symmetric group.

Diagram

Example

Lagrange in action — Fermat's little theorem:
  In the group (ℤ_p)* of order p − 1, every element a satisfies a^(p−1) = e,
  i.e.  a^(p−1) ≡ 1 (mod p)  for gcd(a, p) = 1.

RSA: n = pq,  ed ≡ 1 (mod φ(n)).  By Euler's theorem
  (m^e)^d = m^(ed) = m^(1 + kφ(n)) ≡ m (mod n).
Common exam traps

The identity and each inverse are UNIQUE. (a·b)⁻¹ = b⁻¹·a⁻¹ (order reverses). Every cyclic group is abelian, but not every abelian group is cyclic (Klein four-group). Groups of order p and p² are abelian; the smallest non-abelian group has order 6 (S₃). Lagrange gives a necessary, not sufficient, condition for a subgroup of a given order.

Practice MCQs

Q1. A group (G, *) must satisfy:

  1. closure, associativity, identity, inverses
  2. commutativity only
  3. closure and identity only
  4. associativity and commutativity
Show answer

Answer: A. Abelian adds commutativity.

Q2. Lagrange's theorem: in a finite group, a subgroup's order:

  1. equals |G|
  2. divides |G|
  3. is prime
  4. is even
Show answer

Answer: B. So every element's order divides |G| too.

Q3. A CYCLIC group is one that:

  1. has a cycle in its Cayley graph
  2. is generated by a single element
  3. is abelian but not singly generated
  4. has order 2
Show answer

Answer: B. ℤ and ℤ_n are the only cyclic groups.

Q4. The kernel of a homomorphism f: G → H is:

  1. the image of f
  2. {g : f(g) = e_H} — a normal subgroup of G
  3. H itself
  4. the set of generators
Show answer

Answer: B. f is injective iff ker(f) = {e}.

Q5. Every group of prime order p is:

  1. non-abelian
  2. isomorphic to ℤ_p (cyclic)
  3. trivial
  4. isomorphic to S_p
Show answer

Answer: B. By Lagrange its only subgroups are trivial.
