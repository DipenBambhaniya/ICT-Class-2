Artificial Intelligence, ML & Generative AI

Artificial Intelligence (AI) is the broad field of building systems that perform tasks requiring human-like intelligence. Machine Learning (ML) is a data-driven subset of AI, Deep Learning (DL) is a neural-network-based subset of ML, and Generative AI/Large Language Models (LLMs) are a modern class of models — often built using deep learning — that can produce new content rather than just predict a fixed label. India is investing heavily in this space through the IndiaAI Mission and NITI Aayog's #AIforAll strategy.

Key points

AI vs ML vs DL
AI is the broadest field (building intelligent behaviour, rule-based or data-driven). ML is a subset of AI that learns patterns from data. DL is a subset of ML using multi-layered neural networks that can learn features automatically from raw data.
Learning paradigms
Supervised learning trains on labelled input-output pairs (e.g., spam classification). Unsupervised learning finds structure in unlabelled data (e.g., customer segmentation). Reinforcement learning learns via trial-and-error reward/penalty feedback from an environment (e.g., a game-playing agent).
Neural networks
Built from layered neurons (input → hidden → output) that compute weighted sums passed through non-linear activation functions; trained via backpropagation and gradient descent to minimise prediction error.
Generative AI & LLMs
Generative AI produces new content (text, images, code) rather than only classifying inputs. LLMs are large transformer-based models trained on massive text corpora. Key limitations: hallucination (confident but false output), bias inherited from training data, and the resulting need for human oversight.
India's AI push
The IndiaAI Mission (under MeitY) builds shared compute infrastructure, a datasets platform, startup/innovation support, and a Safe & Trusted AI pillar. NITI Aayog's #AIforAll strategy aims for inclusive AI-driven growth across healthcare, agriculture, education and more.

Example

A government portal deploying an AI-based citizen-services chatbot:
  1. The chatbot is a Machine Learning system: it was trained on many
     examples of citizen queries paired with correct answers/intents
     (supervised learning)
  2. Its language understanding is powered by a Large Language Model
     (a Generative AI system, typically built using Deep Learning /
     transformer neural networks) that can draft natural-language replies
  3. It uses Bhashini-style AI translation so citizens can ask questions
     in their own Indian language

Why human oversight still matters:
  - The LLM might occasionally "hallucinate" an incorrect scheme
    eligibility rule stated with full confidence
  - Officials periodically review chatbot logs and flagged low-confidence
    answers before they are used to update the citizen-facing knowledge
    base, keeping a human in the loop for accuracy and accountability
Common exam traps

AI, ML and DL are NOT synonyms — remember the nesting: AI ⊃ ML ⊃ DL. Reinforcement learning is not the same as supervised learning — RL learns from reward/penalty feedback through interaction, not from a fixed set of labelled examples given upfront. "Hallucination" refers to a model generating fabricated content confidently, not a hardware fault. The IndiaAI Mission is a government (MeitY) programme with multiple pillars (compute, datasets, startups, safe & trusted AI) — don't confuse it with NITI Aayog's #AIforAll, which is the national AI policy strategy rather than the implementing mission.

Practice MCQs

Q1. The correct nesting relationship between AI, ML and DL is:

  1. DL contains ML, which contains AI
  2. AI, ML and DL are three unrelated, non-overlapping fields
  3. AI is the broadest field, ML is a subset of AI, and DL is a further subset of ML
  4. ML contains AI, which contains DL
Show answer

Answer: C. AI is the umbrella discipline; ML is a data-driven approach within AI; DL is a neural-network-based approach within ML.

Q2. Reinforcement learning (RL) is best described as:

  1. A model trained only on data labelled by human annotators in advance
  2. An approach where an agent learns to make decisions by interacting with an environment, receiving rewards or penalties as feedback, and adjusting its behaviour to maximise cumulative reward over time
  3. A method that only finds clusters in unlabelled data
  4. A synonym for supervised learning with no meaningful difference
Show answer

Answer: B. RL is defined by an agent-environment interaction loop with reward-based feedback, unlike supervised learning's static labelled dataset.

Q3. 'Hallucination' in the context of generative AI / LLMs refers to:

  1. The model refusing to answer any question whatsoever
  2. A hardware malfunction in the server running the model
  3. The model generating plausible-sounding but factually incorrect or fabricated content, stated with apparent confidence
  4. A deliberate security feature that blocks all inaccurate output
Show answer

Answer: C. Hallucination describes confidently-stated but false or fabricated output — a well-documented limitation of current generative AI systems.

Q4. The IndiaAI Mission is best described as:

  1. A private multinational company's internal research lab
  2. A single mobile application with no broader programme behind it
  3. An initiative that only funds hardware manufacturing with no AI-specific focus
  4. A comprehensive Government of India initiative that builds shared AI compute infrastructure, datasets platforms, and support for startups/innovation, alongside a focus on safe and trusted AI
Show answer

Answer: D. The IndiaAI Mission is a national umbrella programme spanning compute infrastructure, datasets, innovation/startup support, and safe & trusted AI governance.

Q5. NITI Aayog's national strategy on artificial intelligence is commonly known by the phrase:

  1. #DigitalIndiaOnly
  2. #AIforAll
  3. #MakeInIndiaAI
  4. #SmartCitiesAI
Show answer

Answer: B. NITI Aayog's national AI strategy paper is widely referred to by the tagline '#AIforAll'.
