Linked Lists

A linked list chains nodes, each holding data plus a pointer to the next (and, if doubly linked, the previous). Insert/delete at a known node is O(1) with no shifting, but there is no random access — reaching element k is O(k).

Key points

Node
{ data, next } (singly) or { prev, data, next } (doubly).
Access k-th element
O(k) — follow next pointers. No index arithmetic.
Insert / delete at known position
O(1) pointer surgery (doubly linked needed for O(1) delete given only the node).
Two-pointer tricks
slow/fast for the middle and for cycle detection (Floyd); leader/follower gap of k for n-th-from-end.
Trade-off vs array
No resize/shift cost and grows one node at a time, but one+ pointer per node and poor cache locality (pointer chasing).

Diagram

Example

/* Reverse a singly linked list — O(n) time, O(1) space */
Node *prev = NULL, *cur = head;
while (cur) {
    Node *next = cur->next;
    cur->next = prev;
    prev = cur;
    cur = next;
}
head = prev;

/* Cycle detection: slow = slow->next; fast = fast->next->next; meet ⇒ cycle */
Common exam traps

Indexed access is O(n) — that's the array's job. To change the caller's head pointer in C you pass Node **head. Deleting a list means free-ing each node after saving next. Merge sort (not quicksort) is the natural O(n log n) sort for lists.

Practice MCQs

Q1. Accessing the k-th element of a singly linked list is:

  1. O(1)
  2. O(log k)
  3. O(k)
  4. O(n log n)
Show answer

Answer: C. You must follow k next pointers from the head.

Q2. Inserting at the head of a singly linked list is:

  1. O(1)
  2. O(n)
  3. O(log n)
  4. O(n) without a tail pointer
Show answer

Answer: A. Point the new node at the old head and update head.

Q3. Detecting a cycle in a linked list uses:

  1. sorting
  2. Floyd's slow/fast pointers
  3. a stack
  4. binary search
Show answer

Answer: B. If fast (2 steps) meets slow (1 step), there is a cycle — O(n) time, O(1) space.

Q4. Which is O(1) on a doubly linked list but O(n) on a singly linked list?

  1. insert at head
  2. delete a node given only a pointer to it
  3. traverse forward
  4. search
Show answer

Answer: B. The prev pointer lets you fix the predecessor's link directly.

Q5. An LRU cache is typically built from:

  1. one array
  2. a hash map + doubly linked list
  3. a binary heap
  4. a stack
Show answer

Answer: B. Map for O(1) lookup; list orders by recency, evicting the tail.
