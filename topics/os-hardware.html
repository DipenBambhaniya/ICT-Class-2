Hardware Basics

The OS manages a Von Neumann machine: a CPU (ALU + control unit) fetching instructions and data over a shared bus from a memory hierarchy, with I/O devices, interrupts and DMA.

Key points

Von Neumann model
Instructions and data share one memory and one bus (the 'Von Neumann bottleneck'). Cycle: fetch → decode → execute → write-back.
Memory hierarchy
Registers → L1/L2/L3 cache → RAM → SSD/HDD → tape. Faster = smaller and costlier. Exploits temporal and spatial locality.
Interrupts & DMA
An interrupt diverts the CPU to a handler (saving context). DMA lets a device move a block to/from memory without per-byte CPU work.
Pipelining & hazards
Overlapping instruction stages boosts throughput; data/control/structural hazards cause stalls. Branch prediction hides control hazards.
RISC vs CISC
RISC (ARM, RISC-V): few simple fixed-length instructions, load/store. CISC (x86): rich variable-length instructions.

Example

Instruction cycle (RISC):
  FETCH    load instruction at [PC] into IR;  PC += 4
  DECODE   identify opcode, read source registers
  EXECUTE  ALU computes / address is formed
  MEMORY   load or store (only load/store instructions)
  WRITEBACK put the result into the destination register

Amdahl's law: if 20% of a task is serial, max speedup = 1 / 0.20 = 5x
Common exam traps

A 32-bit address bus limits addressable memory to 2^32 = 4 GB. Higher clock speed does not mean faster: performance = clock × IPC. RAM is volatile; ROM/flash/disk are not. DMA still needs the CPU to set up and to handle the completion interrupt.

Practice MCQs

Q1. The Von Neumann architecture stores:

  1. programs and data in separate memories
  2. programs and data in the same memory
  3. only data in memory
  4. programs in registers
Show answer

Answer: B. One shared memory; the Harvard architecture separates them.

Q2. Which memory is fastest and smallest?

  1. main memory (RAM)
  2. CPU registers
  3. L3 cache
  4. SSD
Show answer

Answer: B. Registers sit at the top of the hierarchy.

Q3. A 32-bit processor can directly address at most:

  1. 2^16 bytes
  2. 2^32 bytes = 4 GB
  3. 2^64 bytes
  4. unlimited
Show answer

Answer: B. The address bus width bounds the space.

Q4. DMA allows:

  1. the CPU to access disk directly
  2. a device to transfer a block to/from memory without per-byte CPU involvement
  3. faster cache
  4. virtual memory
Show answer

Answer: B. The CPU sets it up and gets an interrupt on completion.

Q5. Amdahl's law says parallel speedup is limited by:

  1. the number of cores only
  2. the fraction of the program that stays sequential
  3. the clock speed
  4. the cache size
Show answer

Answer: B. 10% serial ⇒ at most 10x speedup.
