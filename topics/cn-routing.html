Routing Algorithms

Routers build their forwarding tables dynamically using one of two families of algorithm: distance vector (share distances with neighbors) or link state (share the full topology with everyone).

Key points

Distance vector
Each router shares its own routing table with direct neighbors only ("routing by rumor"). Based on the Bellman-Ford algorithm. Example: RIP.
Link state
Each router floods its direct link costs to EVERY router, so all routers build the same topology map, then independently run Dijkstra's algorithm. Example: OSPF.
Count-to-infinity
A classic distance-vector failure mode where a bad route's cost creeps up slowly after a failure. Mitigated by split horizon, poison reverse, hold-down timers.
Path vector
BGP (used between autonomous systems) tracks the whole AS path, letting a router detect a loop by seeing its own AS already in the path.
Convergence
Link state generally converges faster and is more loop-resistant than distance vector, at the cost of more memory/CPU/flooding overhead per router.

Diagram

Example

Count-to-infinity (simplified):

Initially: C -> A costs 2 (via B)   B -> A costs 1 (direct)

Link B-A fails. B doesn't know a better route, but hears
C still claims "cost 2 to A" (stale info) -- B updates to
cost 3 via C. C then hears B's new claim of 3 and updates
to cost 4 via B. This ping-pong continues, slowly climbing
toward "infinity" (e.g. 16 in RIP) before the route is
finally marked unreachable -- this is exactly why link
state's full-topology view avoids this failure mode.
Common exam traps

Distance vector = Bellman-Ford; link state = Dijkstra. RIP is distance vector; OSPF is link state; BGP is path vector (used BETWEEN autonomous systems, not within one). Split horizon alone does not solve every loop scenario — real protocols combine several techniques (split horizon, poison reverse, hold-down timers, triggered updates). Link state needs MORE memory/CPU per router than distance vector, not less.

Practice MCQs

Q1. Distance vector routing is based on which algorithm?

  1. Dijkstra's algorithm
  2. Bellman-Ford
  3. Prim's algorithm
  4. Kruskal's algorithm
Show answer

Answer: B. Each router iteratively relaxes distance estimates from neighbors.

Q2. Link state routing uses which shortest-path algorithm?

  1. Bellman-Ford
  2. Dijkstra's algorithm
  3. Floyd-Warshall exclusively
  4. Kruskal's algorithm
Show answer

Answer: B. Run once every router has the same full topology.

Q3. RIP is an example of which routing family?

  1. Link state
  2. Distance vector
  3. Path vector
  4. Static routing
Show answer

Answer: B. RIP uses hop count as its metric.

Q4. The count-to-infinity problem occurs in:

  1. Link state routing
  2. Distance vector routing
  3. Static routing only
  4. IPv6 addressing
Show answer

Answer: B. Caused by routers trusting neighbor-reported distances without seeing the actual path.

Q5. BGP is best classified as:

  1. A distance vector protocol
  2. A path vector protocol
  3. A pure link state protocol
  4. A protocol used only within a single LAN
Show answer

Answer: B. It tracks the full AS path to detect and avoid loops between autonomous systems.
