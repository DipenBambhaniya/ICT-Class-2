Recursion

A recursive function solves a problem by calling itself on smaller inputs until it reaches a base case. Each call gets its own stack frame, so recursion depth is bounded by the call-stack size.

Key points

Base case
The non-recursive stopping condition. Without one (or without progress toward it) the recursion overflows the stack.
Recursive case
Reduces the problem and calls itself on a strictly smaller sub-input.
Call stack
Each active call keeps an activation record (parameters, locals, return address). Depth d ⇒ d frames.
Tail recursion
The recursive call is the last action; can be compiled to a loop using O(1) stack.
Memoization
Cache subproblem results to turn overlapping exponential recursion (e.g. naive Fibonacci) into linear time.

Diagram

Example

int fact(int n) {
    if (n <= 1) return 1;          /* base case */
    return n * fact(n - 1);         /* recursive case */
}
/* fact(4) → 4*fact(3) → 4*3*fact(2) → 4*3*2*fact(1) → 4*3*2*1 = 24 */

/* naive Fibonacci: O(2^n) time. Memoized: O(n). */
Common exam traps

Naive Fibonacci is exponential time but only O(n) space (one path active at a time). Binary search recursion is T(n)=T(n/2)+O(1) ⇒ O(log n); merge sort is T(n)=2T(n/2)+O(n) ⇒ O(n log n). Every recursion can be rewritten iteratively with an explicit stack.

Practice MCQs

Q1. Every recursive function must have:

  1. a loop
  2. at least one base case
  3. a global variable
  4. return type int
Show answer

Answer: B. Without a base case the recursion never terminates.

Q2. Parameters of each recursive call are stored in:

  1. the heap
  2. a stack frame on the call stack
  3. CPU registers only
  4. the data segment
Show answer

Answer: B. Each call pushes its own activation record.

Q3. Naive recursive Fibonacci has time complexity:

  1. O(n)
  2. O(n log n)
  3. O(2^n)
  4. O(n^2)
Show answer

Answer: C. The call tree branches twice per level with overlapping subproblems.

Q4. T(n) = 2T(n/2) + O(n) solves to:

  1. O(n)
  2. O(n log n)
  3. O(n^2)
  4. O(log n)
Show answer

Answer: B. The merge-sort recurrence — Theta(n log n) by the Master Theorem.

Q5. Tail-call optimization lets a tail-recursive function use:

  1. O(n) stack
  2. O(1) stack
  3. O(log n) stack
  4. no stack
Show answer

Answer: B. With nothing after the call, the current frame is reused like a loop.
