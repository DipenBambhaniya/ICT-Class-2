Data Warehousing

A data warehouse is a subject-oriented, integrated, time-variant, non-volatile store built via ETL from operational systems, designed to support historical analysis and management decision-making.

Key points

Four defining characteristics (Inmon)
Subject-oriented (organized by business entity, not application), Integrated (reconciled across sources), Time-variant (retains history), Non-volatile (loaded, not continuously overwritten).
ETL / ELT
Extract from sources → Transform/clean/reshape → Load into the warehouse. ELT (common on modern cloud warehouses) loads first, then transforms using the warehouse's own compute.
Inmon vs Kimball
Inmon: build one centralized, normalized enterprise warehouse first, then derive data marts. Kimball: build dimensional data marts first, unify via shared "conformed dimensions."
Grain
The level of detail per fact table row — a foundational design decision. Choosing too coarse a grain permanently limits future analysis.
Slowly Changing Dimensions (SCD)
Type 1: overwrite (lose history). Type 2: add a new row with effective dates (preserve full history) — the most common approach.

Diagram

Example

Slowly Changing Dimension — Type 2 (preserve history):

Before: Customer 501, Region = "West"
Customer moves to "East" region.

Type 1 (overwrite):
  Customer 501, Region = "East"   <- history lost

Type 2 (new row, effective dates):
  Customer 501, Region = "West", valid 2022-01-01 to 2024-03-14
  Customer 501, Region = "East", valid 2024-03-15 to present
  -> Old sales still correctly attribute to "West"
Common exam traps

ETL = Extract, Transform, Load (transform BEFORE loading); ELT loads first, then transforms. "Non-volatile" doesn't mean data never changes overall — it means loaded data isn't continuously overwritten like OLTP data. Kimball = bottom-up (marts first); Inmon = top-down (enterprise warehouse first). Choosing too coarse a grain cannot be fixed later without re-collecting detail.

Practice MCQs

Q1. ETL stands for:

  1. Extract, Transfer, Load
  2. Extract, Transform, Load
  3. Evaluate, Test, Launch
  4. Export, Transmit, Log
Show answer

Answer: B. The standard process for populating a data warehouse.

Q2. "Subject-oriented" as a warehouse characteristic means data is organized around:

  1. Specific operational applications
  2. Major business subjects/entities like Customer or Sales
  3. Random categories
  4. Physical storage devices
Show answer

Answer: B. Contrasts with OLTP's application-centric organization.

Q3. A "data mart" is:

  1. An identical copy of the entire warehouse
  2. A smaller subset tailored to a specific department's needs
  3. A type of OLTP system
  4. A retail point-of-sale terminal
Show answer

Answer: B. Can be derived from an enterprise warehouse or built independently.

Q4. A Type 2 Slowly Changing Dimension handles a changed attribute by:

  1. Overwriting the old value
  2. Creating a new row preserving the old value alongside the new one
  3. Deleting the record
  4. Ignoring the change
Show answer

Answer: B. Preserves historical accuracy for past facts.

Q5. "Grain" in fact table design refers to:

  1. The physical storage medium
  2. The level of detail represented by one fact table row
  3. A dimension hierarchy level
  4. An unrelated networking term
Show answer

Answer: B. A foundational, hard-to-change design decision.
