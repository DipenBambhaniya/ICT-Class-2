Binary Heaps

A binary heap is a complete binary tree stored in an array where every parent is ≤ (min-heap) or ≥ (max-heap) its children. It gives O(1) find-extremum, O(log n) insert and extract, and O(n) bulk build — the standard priority queue.

Key points

Array indexing (0-based)
left(i) = 2i+1, right(i) = 2i+2, parent(i) = (i−1)/2. No pointers, no gaps.
insert
Append at the end, then sift up — O(log n).
extract-min/max
Swap root with last, remove, sift down the new root — O(log n).
build-heap
Bottom-up sift-down from index n/2−1 to 0 — O(n), not O(n log n).
Heapsort
Build max-heap O(n), then extract-max n times — O(n log n), in place, not stable.

Example

/* k largest of n items with a size-k min-heap: O(n log k) */
for each x in stream:
    if (heap.size < k)  heap.push(x);
    else if (x > heap.peek()) { heap.pop(); heap.push(x); }
/* heap now holds the k largest; its root is the k-th largest */

/* build-heap: for i = n/2 - 1 down to 0: siftDown(i)   → O(n) */
Common exam traps

build-heap is O(n), not O(n log n). A heap gives no efficient search or ordered traversal (that's a BST). The minimum of a max-heap is in the leaves — O(n) to find. Heapsort is in-place O(n log n) but not stable. Merging two binary heaps is O(n); use a binomial/Fibonacci heap for cheap merge.

Practice MCQs

Q1. In a 0-indexed array heap, the children of index i are at:

  1. i-1 and i+1
  2. 2i and 2i+1
  3. 2i+1 and 2i+2
  4. i/2 and i/2+1
Show answer

Answer: C. 0-indexed: left = 2i+1, right = 2i+2, parent = (i-1)/2.

Q2. Building a heap from an arbitrary array of n elements takes:

  1. O(n log n)
  2. O(n)
  3. O(log n)
  4. O(n^2)
Show answer

Answer: B. Bottom-up sift-down; most nodes are near the leaves and move little.

Q3. extract-min from a heap of n elements is:

  1. O(1)
  2. O(log n)
  3. O(n)
  4. O(log n) amortized only
Show answer

Answer: B. Replace root with the last element and sift it down one path.

Q4. The running median of a stream is maintained with:

  1. one heap
  2. a max-heap (lower half) + a min-heap (upper half)
  3. a sorted list
  4. a BST only
Show answer

Answer: B. The two heap tops straddle the median; rebalance in O(log n).

Q5. Heapsort is NOT:

  1. in place
  2. O(n log n) worst case
  3. stable
  4. comparison-based
Show answer

Answer: C. Sift operations can reorder equal keys.
