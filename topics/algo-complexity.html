Space & Time Complexity

Time and space are independent resources. Space complexity counts auxiliary memory — recursion stack, tables, buffers — and often trades against time.

Key points

Auxiliary space
Extra memory beyond the input. 'In-place' = O(1) (or O(log n)) auxiliary.
Recursion cost
O(depth) stack frames; deep recursion risks stack overflow.
Time–space tradeoff
Precomputed tables / memoization / hashing spend memory to save time; recomputation does the reverse.
Sort space
Merge sort O(n), quicksort O(log n) stack, heapsort O(1), counting sort O(n+k).
DP space reduction
If dp[i] depends only on dp[i-1], keep one row: O(n²) → O(n).

Example

// Fibonacci: O(n) time, O(1) space
long a = 0, b = 1;
for (int i = 2; i <= n; i++) { long t = a + b; a = b; b = t; }

// 0/1 knapsack: O(nW) time; O(nW) space → O(W) by keeping one row
for (int i = 0; i < n; i++)
    for (int w = W; w >= wt[i]; w--)
        dp[w] = max(dp[w], dp[w - wt[i]] + val[i]);
Common exam traps

An O(n²)-time algorithm can use O(1) space (bubble sort) — time and space are separate. Recursive merge sort's stack is O(log n), but its merge buffer is O(n). Iterative binary search is O(1) space; the recursive version is O(log n). 'Total space ≤ O(time)' always holds.

Practice MCQs

Q1. An 'in-place' algorithm uses:

  1. no memory at all
  2. O(1) or O(log n) auxiliary space
  3. O(n) extra space
  4. only the heap
Show answer

Answer: B. Constant (or logarithmic) extra space beyond the input.

Q2. Merge sort's space complexity is:

  1. O(1)
  2. O(log n)
  3. O(n) for the merge buffer
  4. O(n^2)
Show answer

Answer: C. Plus O(log n) recursion stack.

Q3. Which sort is O(n log n) time AND O(1) auxiliary space?

  1. merge sort
  2. heapsort
  3. counting sort
  4. standard quicksort
Show answer

Answer: B. Heapsort sorts in place.

Q4. Reducing a 2D DP to 1D works when:

  1. the table is large
  2. dp[i][*] depends only on dp[i-1][*]
  3. the DP is a graph
  4. n is small
Show answer

Answer: B. Keep one or two rows instead of the full table.

Q5. The recursion depth of the Tower of Hanoi solution for n disks is:

  1. O(1)
  2. O(n)
  3. O(2^n)
  4. O(n^2)
Show answer

Answer: B. It makes 2^n-1 moves but the stack is only n deep.
