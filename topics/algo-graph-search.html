Graph Search

Graph search finds paths and reachable states. BFS (queue) gives fewest-edge paths; DFS (stack) gives structure; uniform-cost/Dijkstra order by path cost; A* adds a heuristic to head toward the goal.

Key points

BFS
FIFO queue; fewest-edge shortest path in unweighted graphs; O(V+E); frontier can be O(V).
DFS
Stack/recursion; O(V+E); O(depth) memory; cycle detection, topological sort, SCCs.
Uniform-cost search
= Dijkstra: expand the lowest-g frontier node; optimal for non-negative weights.
A*
Order by f = g + h. Optimal if h is admissible (never overestimates); efficient if h is informative.
IDDFS / bidirectional
IDDFS: BFS-optimal with O(bd) memory. Bidirectional: O(b^(d/2)) by meeting in the middle.

Example

// BFS
q.push(s); dist[s] = 0; seen[s] = true;
while (!q.empty()) {
    u = q.pop();
    for (v : adj[u])
        if (!seen[v]) { seen[v] = true; dist[v] = dist[u] + 1; q.push(v); }
}

// A*: priority = g(v) + h(v);  h = 0 ⇒ Dijkstra;  ignore g ⇒ greedy best-first
Common exam traps

BFS gives shortest paths only for unit weights; weighted ⇒ Dijkstra. A* needs an admissible heuristic for optimality (consistent ⇒ each node expanded once). Greedy best-first (h only) is neither optimal nor complete. DFS can loop forever on infinite graphs; BFS/IDDFS are complete. 2PL ≠ 2-phase commit; likewise BFS ≠ Dijkstra.

Practice MCQs

Q1. To find the fewest-edge path in an unweighted graph, use:

  1. DFS
  2. BFS
  3. Dijkstra
  4. Bellman-Ford
Show answer

Answer: B. BFS layers = edge distance.

Q2. A* search orders the frontier by:

  1. g(n) only
  2. h(n) only
  3. f(n) = g(n) + h(n)
  4. random
Show answer

Answer: C. g = cost so far, h = estimate to goal.

Q3. A* is optimal if the heuristic is:

  1. fast
  2. admissible (never overestimates)
  3. zero
  4. monotone only
Show answer

Answer: B. Consistency additionally avoids re-expansions.

Q4. 0-1 BFS (weights 0 or 1) uses a:

  1. min-heap
  2. deque (push 0-edges front, 1-edges back)
  3. stack
  4. plain queue
Show answer

Answer: B. Keeps the frontier sorted by distance in O(V+E).

Q5. IDDFS space complexity is:

  1. O(b^d) like BFS
  2. O(bd) — linear like DFS
  3. O(1)
  4. O(d^2)
Show answer

Answer: B. It keeps only the current path but finds the shallowest goal.
