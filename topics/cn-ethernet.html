LAN Technologies (Ethernet)

Ethernet (IEEE 802.3) is the dominant wired LAN technology. Modern switched, full-duplex Ethernet has mostly retired the collision-handling machinery of its original shared-medium design, but that history still shows up on exams.

Key points

CSMA/CD
Classic shared-medium Ethernet: sense the carrier, transmit, detect collisions, jam and back off exponentially. Irrelevant on modern full-duplex switched links.
MAC address
48-bit address burned into the NIC, e.g. 00:1A:2B:3C:4D:5E. First 24 bits are the OUI (vendor).
Frame format
Preamble, destination MAC, source MAC, EtherType/length, payload (46-1500 bytes), FCS (CRC-32 trailer).
Hub vs Switch
A hub is a Physical-layer repeater (one shared collision domain). A switch learns MAC-to-port mappings and forwards intelligently, giving each port its own collision domain.
VLANs
802.1Q tags let one physical switch fabric be logically split into multiple isolated broadcast domains.

Example

How a switch learns and forwards:

1. Frame arrives on port 3, source MAC = AA:AA:AA:AA:AA:AA
   -> Switch records: AA:AA:AA:AA:AA:AA is on port 3

2. Destination MAC = BB:BB:BB:BB:BB:BB, not yet in the table
   -> Switch FLOODS the frame out every port except port 3

3. Later, BB:...:BB replies; the switch now learns port 5 -> BB:...:BB
   -> Future frames to BB:...:BB go ONLY to port 5 (no more flooding)
Common exam traps

Minimum Ethernet frame = 64 bytes; standard max payload (MTU) = 1500 bytes. A hub floods everything (Layer 1); a switch learns and forwards selectively (Layer 2). CSMA/CD is about COLLISION DETECTION and is largely obsolete on full-duplex switched links — Wi-Fi uses CSMA/CA (avoidance) instead, not CD. VLANs are configured with 802.1Q tags, not IP addresses.

Practice MCQs

Q1. Ethernet is standardized under which IEEE working group?

  1. 802.11
  2. 802.3
  3. 802.15
  4. 802.1
Show answer

Answer: B. 802.3 covers wired Ethernet's Physical and MAC sublayer.

Q2. A MAC address is:

  1. A 32-bit logical address from an ISP
  2. A 48-bit address burned into the NIC
  3. The same as an IP address
  4. A random session ID
Show answer

Answer: B. Written as six hex byte pairs.

Q3. The minimum Ethernet frame size is:

  1. 14 bytes
  2. 64 bytes
  3. 1500 bytes
  4. 1518 bytes
Show answer

Answer: B. This ensured collisions could be detected within the transmission time on legacy shared segments.

Q4. A switch improves on a hub mainly by:

  1. Using a faster cable type
  2. Forwarding frames only to the relevant port, reducing collisions
  3. Increasing the maximum frame size
  4. Removing the need for MAC addresses
Show answer

Answer: B. Each port becomes its own collision domain.

Q5. A VLAN is used to:

  1. Increase cable distance
  2. Logically segment one physical switch into multiple isolated broadcast domains
  3. Replace IP addressing
  4. Encrypt traffic
Show answer

Answer: B. 802.1Q tags identify which VLAN a frame belongs to.
