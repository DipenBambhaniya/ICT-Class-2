Searching

Locating a value: linear scan O(n) on anything; binary search O(log n) on sorted data; hashing O(1) average with no order. The right structure depends on how the data changes and what queries you need.

Key points

Linear search
O(n), no preconditions.
Binary search
O(log n) on a SORTED, randomly-accessible array; also 'binary search on the answer' for any monotone predicate.
Hashing
O(1) average lookup, O(n) worst; no ordered operations.
Balanced BST / skip list
O(log n) with successor, range and min/max queries.
Exponential / interpolation / jump search
Unknown size (exp), uniform data (interp, O(log log n)), block scan (jump, O(√n)).

Example

// Binary search — overflow-safe midpoint
int lo = 0, hi = n - 1;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == key) return mid;
    if (a[mid] < key) lo = mid + 1; else hi = mid - 1;
}
return -1;   // or 'lo' = insertion point (lower_bound)
Common exam traps

Compute the midpoint as lo + (hi-lo)/2 to avoid overflow. Binary search needs sorted data — maintaining that under inserts is O(n) each, whereas a hash table inserts in O(1). Hashing has an O(n) worst case and no ordered iteration. 'Peak element' can be found in O(log n) by moving toward the larger neighbour.

Practice MCQs

Q1. Binary search requires the data to be:

  1. unsorted
  2. sorted and randomly accessible
  3. hashed
  4. in a linked list
Show answer

Answer: B. It discards half the range each comparison.

Q2. Hash table search has average / worst time:

  1. O(1) / O(1)
  2. O(1) / O(n)
  3. O(log n) / O(n)
  4. O(n) / O(n)
Show answer

Answer: B. Collisions or a poor hash collapse it to a list.

Q3. The safe midpoint formula is:

  1. (lo + hi) / 2
  2. lo + (hi - lo) / 2
  3. hi / 2
  4. (lo * hi) / 2
Show answer

Answer: B. Avoids integer overflow for large lo + hi.

Q4. 'Binary search on the answer' applies when:

  1. the feasibility function is monotonic in the parameter
  2. the array is unsorted
  3. there is no ordering
  4. the answer is a string
Show answer

Answer: A. If capacity C works, any C' > C works.

Q5. To find the FIRST occurrence of a key with duplicates:

  1. plain binary search
  2. lower-bound binary search (keep going left on a match)
  3. linear search from the end
  4. hashing
Show answer

Answer: B. Record the match and continue left.
