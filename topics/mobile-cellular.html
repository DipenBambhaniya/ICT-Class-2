Cellular Technologies

Mobile connectivity evolved from analog voice-only 1G through digital GSM/CDMA 2G, higher-speed 3G, to all-IP 4G/LTE — each generation adding capability by changing how many users share the radio spectrum and how the network is architected.

Key points

Generations
1G analog voice → 2G digital voice+SMS (GSM/CDMA) → 3G mobile internet (UMTS/CDMA2000) → 4G all-IP, high-speed (LTE, VoLTE).
GSM vs CDMA
GSM uses TDMA + a removable SIM card; classic CDMA uses code-based spreading and traditionally identified devices by ESN/MEID rather than a SIM.
Multiple access
FDMA (frequency slots), TDMA (time slots), CDMA (unique codes on a shared band) — different ways to let many users share limited spectrum.
Network components
BTS (radio) → BSC (controls several BTS) → MSC (call switching); HLR (home subscriber data) and VLR (visiting subscriber data) support roaming.
Handoff / handover
Transferring an active connection from one cell to another as a user moves — soft (CDMA, overlapping) vs hard (GSM, break-before-make).

Diagram

Example

A GSM call handoff as a subscriber drives between cells:
  1. Phone is in Cell A, talking to BTS-A, controlled by BSC-1
  2. Signal strength to BTS-A weakens as the phone nears Cell B
  3. BSC-1 (via the MSC) arranges a handover to BTS-B in Cell B
  4. GSM performs a "hard" handover: the old radio link breaks
     just before the new one is established (brief gap)
  5. VLR data is updated to reflect the phone's new serving area

Contrast: a CDMA "soft" handover keeps BOTH BTS-A and BTS-B connections
briefly active simultaneously, only dropping the old one once the new
one is confirmed good — reducing the chance of a dropped call.
Common exam traps

TDMA/FDMA/CDMA are multiple-access techniques, not generations — GSM (2G) uses TDMA, classic CDMA networks use code-division. VoLTE carries voice as IP data over 4G; earlier generations used circuit-switched voice. HLR = permanent home-subscriber data; VLR = temporary visiting-subscriber data (including roamers) — these are frequently swapped in questions.

Practice MCQs

Q1. GSM stands for:

  1. General Satellite Mobile
  2. Global System for Mobile Communications, a widely adopted 2G digital cellular standard
  3. Global Signal Modulation
  4. Ground Station Module
Show answer

Answer: B. GSM became the dominant 2G standard internationally, especially outside North America.

Q2. CDMA stands for:

  1. Cellular Data Management Application
  2. Code Division Multiple Access, where users share the same frequency band simultaneously, distinguished by unique codes
  3. Central Distribution Mobile Antenna
  4. Cell Division Multiplexing Array
Show answer

Answer: B. CDMA's spread-spectrum approach lets many users transmit on the same frequencies at once.

Q3. 4G cellular networks are primarily defined by:

  1. A return to analog transmission
  2. LTE (Long Term Evolution) technology, offering an all-IP architecture and much higher data speeds than 3G
  3. GSM's original 2G design
  4. The elimination of cellular towers
Show answer

Answer: B. LTE's all-IP design and higher bandwidth marked a significant architectural shift from earlier generations.

Q4. A handoff/handover in a cellular network occurs when:

  1. A subscriber cancels their service
  2. A mobile device's active connection is transferred from one cell/base station to another as the user moves
  3. A SIM card is physically swapped
  4. A device is powered off
Show answer

Answer: B. Seamless handoffs are essential for maintaining calls/data sessions as users move between cell coverage areas.

Q5. The HLR (Home Location Register) stores:

  1. Only temporary visitor information
  2. Permanent subscriber information (like IMSI details and subscribed services) for a network's own subscribers
  3. The device's app store purchase history
  4. Cellular tower maintenance logs
Show answer

Answer: B. The HLR is the authoritative, permanent record for a carrier's own subscribers — the VLR instead holds temporary visitor data.
