Sets, Relations, Functions

Sets are unordered collections; relations are subsets of a Cartesian product; functions are relations that assign exactly one output per input. Cardinality, equivalence relations, partial orders and the injective/surjective/bijective classification are the core.

Key points

Set identities
|P(A)| = 2^|A|; |A ∪ B| = |A| + |B| − |A ∩ B| (inclusion-exclusion); De Morgan; distributive laws.
Relation properties
Reflexive (aRa), symmetric (aRb ⇒ bRa), antisymmetric (aRb ∧ bRa ⇒ a=b), transitive (aRb ∧ bRc ⇒ aRc).
Equivalence relation
Reflexive + symmetric + transitive ⇒ partitions the set into disjoint equivalence classes (and vice versa).
Partial order
Reflexive + antisymmetric + transitive (e.g. ⊆, divisibility). A total order compares every pair.
Function types
Injective (distinct inputs → distinct outputs), surjective (range = codomain), bijective (both — invertible). #functions = n^m; for finite equal-size sets, injective ⇔ surjective ⇔ bijective.

A = {1,2,3},  B = {3,4}

Relation "≡ (mod 3)" on Z: reflexive, symmetric, transitive ⇒ equivalence
  classes {…,-3,0,3,…}, {…,-2,1,4,…}, {…,-1,2,5,…}
Common exam traps

The empty set is a subset of EVERY set (vacuously). |P(A)| = 2^|A|, not 2·|A|. For INFINITE sets, injective does not imply surjective (n ↦ n+1 on ℕ). An equivalence relation partitions; a partial order does not. Antisymmetric ≠ 'not symmetric' — the identity relation is both symmetric and antisymmetric.

Practice MCQs

Q1. The power set of an n-element set has:

  1. n elements
  2. 2n elements
  3. 2^n elements
  4. n! elements
Show answer

Answer: C. Each element is in or out of a subset.

Q2. An EQUIVALENCE relation is:

  1. reflexive, symmetric, transitive
  2. reflexive, antisymmetric, transitive
  3. symmetric only
  4. transitive only
Show answer

Answer: A. It partitions the set into equivalence classes.

Q3. A function f is INJECTIVE if:

  1. every codomain element has a preimage
  2. f(a1) = f(a2) implies a1 = a2
  3. |A| = |B|
  4. f is increasing
Show answer

Answer: B. Distinct inputs give distinct outputs.

Q4. The number of functions from an m-set to an n-set is:

  1. m^n
  2. n^m
  3. mn
  4. n!/(n-m)!
Show answer

Answer: B. Each of m inputs picks one of n outputs.

Q5. The pigeonhole principle states:

  1. every function is injective
  2. if n items go into m < n boxes, some box has ≥ 2 items
  3. sets are countable
  4. functions compose
Show answer

Answer: B. Generalized: some box has ≥ ⌈n/m⌉ items.
