Programming in C

C is a small, statically-typed, procedural language that maps closely to the machine: manual memory management, pointers, and no runtime safety net. Understanding its memory model is the key to everything else.

Key points

Data types & sizes
char (1 byte), int (≥2, usually 4), float/double; sizes are implementation-defined. Use sizeof, never assume.
Storage classes
auto (default local), register, static (persists, file/local scope), extern (defined elsewhere).
Pointers
A variable holding an address. *p dereferences; &x takes an address; p->m is (*p).m.
Memory regions
Code, static/global (zero-initialized), stack (automatic, LIFO), heap (malloc/free — you manage it).
Undefined behavior
Out-of-bounds access, use-after-free, signed overflow, modifying a variable twice between sequence points — the compiler may do anything.

Diagram

Example

#include <stdlib.h>
int *make_array(int n) {
    int *a = malloc(n * sizeof *a);   /* heap; check for NULL in real code */
    for (int i = 0; i < n; i++) a[i] = i * i;
    return a;                          /* ok: heap memory outlives the function */
}
/* caller must free() the result — C has no garbage collector */
Common exam traps

sizeof(int) is not guaranteed to be 4. An array name decays to a pointer except under sizeof/&. char c = 'A' stores 65. Returning the address of a local (stack) variable is undefined behavior; returning heap memory is fine.

Practice MCQs

Q1. Which is NOT a storage class in C?

  1. auto
  2. register
  3. static
  4. volatile
Show answer

Answer: D. volatile is a type qualifier, not a storage class. The storage classes are auto, register, static, extern.

Q2. malloc returns:

  1. char *
  2. int *
  3. void *
  4. the requested type
Show answer

Answer: C. void *, implicitly convertible to any object pointer type.

Q3. a[i] is exactly equivalent to:

  1. *(a + i)
  2. *a + i
  3. a + i
  4. &a[i]
Show answer

Answer: A. Subscripting is defined as *(a+i), which is why i[a] is also legal.

Q4. A static local variable:

  1. is destroyed on return
  2. persists across calls, initialized once
  3. is visible to other files
  4. cannot be initialized
Show answer

Answer: B. static gives static storage duration with local scope.

Q5. int x=5; printf("%d", x++ + ++x); is:

  1. 11
  2. 12
  3. undefined behavior
  4. 10
Show answer

Answer: C. x is modified twice with no sequence point between — undefined behavior.
