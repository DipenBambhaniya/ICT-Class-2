Dynamic Programming

DP solves problems with optimal substructure AND overlapping subproblems by computing each subproblem once. Top-down = memoized recursion; bottom-up = tabulation. Design: state, transition, base case, order.

Key points

Optimal substructure
An optimal solution is built from optimal sub-solutions.
Overlapping subproblems
The same subproblem recurs many times — the reason to cache (vs plain divide & conquer).
Memoization vs tabulation
Top-down computes only needed states; bottom-up avoids recursion overhead and deep-stack limits.
Classic DPs
LCS / edit distance O(mn); 0/1 knapsack O(nW); matrix chain O(n³); LIS O(n log n).
Pseudo-polynomial
Knapsack's O(nW) is exponential in W's bit length — not truly polynomial.

Diagram

Example

// 0/1 knapsack, O(nW) time, O(W) space
int[] dp = new int[W + 1];
for (int i = 0; i < n; i++)
    for (int w = W; w >= wt[i]; w--)
        dp[w] = Math.max(dp[w], dp[w - wt[i]] + val[i]);
return dp[W];

// Fibonacci in O(log n): matrix power of [[1,1],[1,0]]
Common exam traps

DP needs overlapping subproblems — disjoint ones are plain divide & conquer. Coin-change 'number of ways' must loop coins outside, amounts inside (else it counts permutations). Longest SIMPLE path in a general graph has no polynomial DP (it's NP-hard) but is easy on a DAG. Reducing DP space to O(n) loses the ability to reconstruct the path directly.

Practice MCQs

Q1. Dynamic programming applies when a problem has:

  1. independent subproblems only
  2. optimal substructure AND overlapping subproblems
  3. no recursion
  4. a greedy-choice property
Show answer

Answer: B. Overlap makes caching pay off.

Q2. Top-down DP is also called:

  1. tabulation
  2. memoization
  3. iteration
  4. greedy
Show answer

Answer: B. Recursion plus a cache.

Q3. The 0/1 knapsack DP is 'pseudo-polynomial' because its time is polynomial in:

  1. the number of items only
  2. n and the numeric VALUE of W, not W's bit length
  3. log W
  4. nothing
Show answer

Answer: B. O(nW) = O(n·2^b) is exponential in b bits.

Q4. Edit distance dp[i][j] takes the min of:

  1. only substitution
  2. match/substitute, insert, delete
  3. only insert and delete
  4. transposition only
Show answer

Answer: B. Three operations, each +1 (or +0 on a match).

Q5. Longest Increasing Subsequence can be computed in:

  1. O(n)
  2. O(n^2) DP or O(n log n) with binary search
  3. O(2^n)
  4. O(n^3)
Show answer

Answer: B. The O(n log n) method keeps the smallest tail per length.
