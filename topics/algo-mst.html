Minimum Spanning Trees

An MST connects all V vertices with V−1 edges of minimum total weight. Kruskal (sort edges + union-find) and Prim (grow from a vertex with a heap) are both greedy and correct by the cut property.

Key points

Spanning tree
V−1 edges, connected, acyclic. MST minimizes the total weight.
Kruskal
Sort edges ascending; add an edge if its endpoints are in different components (union-find). O(E log E).
Prim
From a start vertex, repeatedly add the cheapest edge crossing to an outside vertex. O((V+E) log V) with a heap; O(V²) with an array (best for dense graphs).
Cut property
The minimum-weight edge crossing any cut is in some MST. Distinct weights ⇒ unique MST.
Also solves
Minimum bottleneck (minimax edge) spanning tree; single-linkage clustering; MST-based 2-approx TSP.

Example

// Kruskal
sort edges by weight
for (u, v, w) in edges:
    if find(u) != find(v):        // different components
        union(u, v); mstWeight += w
        if (--edgesNeeded == 0) break   // V-1 edges added

// Prim: heap keyed by 'cheapest edge from the tree to this outside vertex'
Common exam traps

MST ≠ shortest-path tree (different objectives). Adding a constant to every edge weight does NOT change the MST (all spanning trees gain the same (V−1)·c). A bridge is in every spanning tree; the unique heaviest edge of a cycle is in none. Kruskal on a disconnected graph yields a spanning FOREST.

Practice MCQs

Q1. A spanning tree of a connected graph with V vertices has:

  1. V edges
  2. V - 1 edges
  3. E - 1 edges
  4. 2V edges
Show answer

Answer: B. Connected and acyclic.

Q2. Kruskal's algorithm processes edges:

  1. in arbitrary order
  2. in increasing weight order, adding an edge if it joins two components
  3. in decreasing weight order
  4. by DFS order
Show answer

Answer: B. Union-find rejects cycle-forming edges.

Q3. The cut property states:

  1. the heaviest cycle edge is not in any MST
  2. for any cut, the minimum-weight crossing edge is in some MST
  3. every MST has V edges
  4. MSTs are unique
Show answer

Answer: B. This proves Prim and Kruskal correct.

Q4. An MST is UNIQUE if:

  1. the graph is connected
  2. all edge weights are distinct
  3. it has no leaves
  4. it is planar
Show answer

Answer: B. Distinct weights force a unique min crossing edge.

Q5. Prim's algorithm is preferred over Kruskal's when the graph is:

  1. sparse
  2. dense (E close to V^2)
  3. a tree
  4. disconnected
Show answer

Answer: B. Prim with an array is O(V^2); Kruskal's sort dominates on dense graphs.
