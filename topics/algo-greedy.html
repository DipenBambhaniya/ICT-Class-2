Greedy Algorithms

A greedy algorithm makes the locally optimal choice at each step and never reconsiders. It is correct only when the problem has the greedy-choice property and optimal substructure — proven by an exchange argument or matroid theory.

Key points

Greedy-choice property
A globally optimal solution is reachable by locally optimal choices.
Activity selection
Pick the activity that finishes earliest, repeat among the compatible rest. O(n log n).
Fractional knapsack
Take items by decreasing value/weight ratio (splitting the last). 0/1 knapsack does NOT yield to this — needs DP.
Huffman coding
Repeatedly merge the two lowest-frequency nodes ⇒ optimal prefix code.
Exchange argument
Show any optimal solution can be transformed toward the greedy one without getting worse.

Diagram

Example

// Fractional knapsack, capacity W
sort items by value/weight descending
for each item:
    if (item.weight <= W) { take all; W -= item.weight; value += item.value; }
    else { take fraction W/item.weight; value += item.value * W/item.weight; break; }

// Coin change {1,3,4}, amount 6: greedy gives 4+1+1 (3 coins); optimal is 3+3 (2)
Common exam traps

Greedy is optimal only with a proof — 0/1 knapsack, general coin change, and longest common subsequence all defeat naive greedy and need DP. Activity selection must sort by FINISH time. Dijkstra (greedy) fails with negative edges. Set-cover's greedy is only an O(log n)-approximation.

Practice MCQs

Q1. For a greedy algorithm to be correct, the problem must have:

  1. overlapping subproblems
  2. the greedy-choice property AND optimal substructure
  3. a convex objective only
  4. no constraints
Show answer

Answer: B. Local choices must lead to a global optimum.

Q2. Activity selection greedily picks:

  1. the shortest activity
  2. the activity that finishes earliest
  3. the one that starts earliest
  4. randomly
Show answer

Answer: B. Earliest finish leaves the most room.

Q3. The 0/1 knapsack problem is:

  1. solved greedily by value/weight ratio
  2. NOT solvable by that greedy strategy; needs DP
  3. always O(n log n)
  4. in P only for small values
Show answer

Answer: B. The top-ratio item can block a better combination.

Q4. Huffman coding repeatedly:

  1. splits the highest-frequency symbol
  2. merges the two lowest-frequency nodes
  3. assigns fixed-length codes
  4. sorts the whole alphabet
Show answer

Answer: B. A priority queue yields the two rarest nodes.

Q5. Greedy coin change fails for coins {1,3,4}, amount 6. The optimal is:

  1. 3 coins (4+1+1)
  2. 2 coins (3+3)
  3. 6 coins
  4. impossible
Show answer

Answer: B. Greedy takes 4 first and loses.
