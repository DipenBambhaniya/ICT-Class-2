Binary Search Trees

A BST keeps keys ordered: for every node, all left-subtree keys are smaller and all right-subtree keys are larger. Search, insert and delete cost O(height) — O(log n) if balanced, O(n) if not. Self-balancing variants (AVL, Red-Black) guarantee O(log n).

Key points

BST property
A whole-subtree condition, not just parent vs child. In-order traversal is strictly sorted.
Search / insert
Compare and go left (smaller) or right (larger); insert becomes a new leaf where the search fails.
Delete
Leaf: remove. One child: splice past. Two children: replace key with in-order successor (min of right subtree), then delete that.
Degeneration
Inserting sorted data builds a chain of height n — O(n) per op.
Balanced BSTs
AVL (strict, |bf|≤1, faster lookups) and Red-Black (looser, fewer rotations, faster updates); B-trees for disk.

Example

Node *search(Node *t, int k) {
    if (!t || t->key == k) return t;
    return k < t->key ? search(t->left, k) : search(t->right, k);
}
/* Insert 1,2,3,4,5 in order → right-skewed chain, height 4, O(n) ops   */
/* Balanced BST from sorted array: pick the middle element as the root  */
Common exam traps

Checking only left < node < right locally is wrong — pass down (min,max) bounds or verify the in-order sequence is increasing. Plain BSTs degrade to O(n) on sorted input, which is why libraries use balanced trees. Number of distinct BST shapes on n keys = the n-th Catalan number.

Practice MCQs

Q1. The BST property says, for every node:

  1. left child > parent > right child
  2. all left-subtree keys < node's key < all right-subtree keys
  3. the tree is complete
  4. the root is the median
Show answer

Answer: B. It is a whole-subtree condition.

Q2. Worst-case BST search time is:

  1. O(log n)
  2. O(n) (degenerate chain)
  3. O(1)
  4. O(sqrt n)
Show answer

Answer: B. Sorted insertion order produces a linked-list-shaped tree.

Q3. To delete a node with two children:

  1. just remove it
  2. replace its key with the in-order successor, then delete that node
  3. delete the whole subtree
  4. rotate it to a leaf
Show answer

Answer: B. The successor is the min of the right subtree and has ≤1 child.

Q4. An AVL tree rebalances when a node's balance factor reaches:

  1. 0
  2. +/-1
  3. +/-2
  4. any non-zero value
Show answer

Answer: C. Rotations restore |height(left) - height(right)| ≤ 1.

Q5. Number of structurally distinct BSTs on keys 1..n is:

  1. n!
  2. 2^n
  3. the n-th Catalan number
  4. n^2
Show answer

Answer: C. C_n = (2n)! / ((n+1)! n!).
