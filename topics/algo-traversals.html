Tree & Graph Traversals

Traversal is the systematic visiting of every node. Trees have four standard orders; graphs need a visited set to handle cycles. DFS uses a stack, BFS uses a queue.

Key points

Pre / In / Post-order
Root-L-R / L-Root-R / L-R-Root. In-order of a BST is sorted; post-order frees a tree.
Level-order (BFS)
Queue; visits level by level; unit-weight shortest paths.
Graph DFS
Stack / recursion; cycle detection, topological sort, SCCs, bridges. O(V+E).
Edge types (directed DFS)
Tree, back (⇒ cycle), forward, cross.
Reconstruction
pre + in (or post + in) with distinct keys ⇒ unique tree; pre + post is ambiguous for single-child nodes.

Example

void dfs(int u) {              // graph DFS, O(V + E)
    visited[u] = true;
    for (int v : adj[u])
        if (!visited[v]) dfs(v);
}

// Topological sort: DFS, push u on finish, then reverse the list
// Cycle in directed graph: a back edge to a vertex still 'in progress'
Common exam traps

Graph traversal needs a visited set (trees don't). Mark BFS vertices visited on ENQUEUE. In-order 'sorted' property is BST-only. On an adjacency matrix, BFS/DFS are O(V²). Recursive DFS depth can reach O(V) — use an explicit stack for huge graphs.

Practice MCQs

Q1. In-order traversal of a BST yields keys:

  1. in random order
  2. in ascending sorted order
  3. descending
  4. by level
Show answer

Answer: B. Left < node < right.

Q2. Level-order tree traversal uses a:

  1. stack
  2. queue
  3. priority queue
  4. recursion only
Show answer

Answer: B. Enqueue root, then its children.

Q3. Which pair CANNOT uniquely rebuild a general binary tree?

  1. pre + in
  2. post + in
  3. pre + post
  4. level + in
Show answer

Answer: C. Ambiguous for single-child nodes.

Q4. A cycle in a DIRECTED graph is detected by DFS finding:

  1. a cross edge
  2. a back edge to a vertex on the recursion stack
  3. a forward edge
  4. any repeated vertex
Show answer

Answer: B. Three-color marking distinguishes it.

Q5. Topological sort via DFS is:

  1. discovery order
  2. reverse of finish times
  3. BFS order
  4. sorted vertex ids
Show answer

Answer: B. Push on finish, then reverse.
