Queues

A queue is a FIFO container: elements leave in arrival order. Enqueue at the rear, dequeue at the front, both O(1) with the right implementation. Queues model fair, arrival-order processing and power BFS.

Key points

Ends
front (dequeue / peek) and rear (enqueue).
Circular queue
Fixed array with wrap-around indices (i+1) % cap; avoids the O(n) shift of a naive array queue. Holds cap−1 items (or use a count).
Linked queue
Singly linked list with head + tail pointers ⇒ O(1) both ends, unbounded.
Deque
Double-ended queue: insert/remove at both ends. Restrict to one end ⇒ stack.
Priority queue
Not FIFO — serves by key/priority; a binary heap gives O(log n) insert & extract.

Diagram

Example

/* BFS shortest path (unweighted) */
enqueue(source); dist[source] = 0; visited[source] = 1;
while (!empty(q)) {
    u = dequeue();
    for each neighbor v of u:
        if (!visited[v]) { visited[v] = 1; dist[v] = dist[u] + 1; enqueue(v); }
}
/* vertices leave the queue in non-decreasing order of distance */
Common exam traps

A naive array queue that shifts on dequeue is O(n); use a circular buffer. In BFS, mark a vertex visited when enqueued, not when dequeued. BFS gives shortest paths only with unit edge weights. Round-robin scheduling = circular queue; FCFS = plain FIFO queue.

Practice MCQs

Q1. A queue follows which principle?

  1. LIFO
  2. FIFO
  3. priority order
  4. random
Show answer

Answer: B. First In, First Out.

Q2. Which traversal uses a queue?

  1. DFS
  2. BFS
  3. in-order
  4. topological sort via DFS
Show answer

Answer: B. BFS explores level by level in discovery order.

Q3. In a circular array of size n (one slot sacrificed), capacity is:

  1. n
  2. n - 1
  3. n + 1
  4. n / 2
Show answer

Answer: B. Leaving one slot empty distinguishes full from empty.

Q4. Round-robin CPU scheduling uses a:

  1. stack
  2. circular queue
  3. priority queue
  4. binary tree
Show answer

Answer: B. Each process gets a slice, then goes to the back of the ready queue.

Q5. A linked-list queue needs a tail pointer to make which operation O(1)?

  1. dequeue
  2. enqueue
  3. search
  4. reverse
Show answer

Answer: B. Without it, appending at the rear is O(n).
