Trees

A tree is a connected acyclic graph: n nodes, n−1 edges, one root, each node reached by exactly one path. Binary trees (≤2 children) are the workhorse; traversals visit every node in O(n).

Key points

Height / depth
Depth of a node = edges from the root (root = 0). Height of the tree = max depth. Balanced ⇒ O(log n); degenerate ⇒ O(n).
Traversals (DFS)
Pre-order (Root,L,R), In-order (L,Root,R), Post-order (L,R,Root) — all O(n), recursion depth = height.
Level-order (BFS)
Visit level by level using a queue.
Shapes
Full (0 or 2 children), complete (levels full L→R except last), perfect (full + all leaves same depth).
Reconstruction
pre-order + in-order (distinct keys) ⇒ unique tree. pre + post ⇒ unique only for full binary trees.

Example

void inorder(Node *t) {
    if (!t) return;             /* base case: empty subtree */
    inorder(t->left);
    visit(t->key);
    inorder(t->right);
}
/* Height:  h(t) = t ? 1 + max(h(t->left), h(t->right)) : -1  */
/* Level-order: enqueue root; dequeue node, enqueue its children */
Common exam traps

A tree with n nodes always has exactly n−1 edges and n+1 NULL links. In-order of a BST is sorted (not true for a general binary tree). Post-order is the one to use for freeing a tree or computing subtree aggregates. A skewed tree has height n−1 and O(n) operations.

Practice MCQs

Q1. A tree with n nodes has how many edges?

  1. n
  2. n - 1
  3. n + 1
  4. 2n
Show answer

Answer: B. Connected and acyclic ⇒ n-1 edges.

Q2. In-order traversal of a binary search tree yields keys:

  1. in random order
  2. in ascending sorted order
  3. in descending order
  4. level by level
Show answer

Answer: B. Left < node < right, so L-Root-R is sorted.

Q3. Level-order traversal uses a:

  1. stack
  2. queue
  3. priority queue
  4. hash set
Show answer

Answer: B. Enqueue a node, then enqueue its children.

Q4. Max nodes in a binary tree of height h (root at 0) is:

  1. 2^h
  2. 2^(h+1) - 1
  3. h^2
  4. 2h + 1
Show answer

Answer: B. A perfect tree: 1 + 2 + 4 + ... + 2^h.

Q5. Which traversal pair uniquely rebuilds any binary tree with distinct keys?

  1. pre + post
  2. pre + in (or post + in)
  3. in alone
  4. level-order alone
Show answer

Answer: B. pre/post give the root; in-order splits the subtrees. pre+post is ambiguous for single-child nodes.
