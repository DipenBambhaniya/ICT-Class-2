Partial Orders & Lattices

A poset orders some (not necessarily all) pairs. A lattice is a poset where every pair has a least upper bound (join, ∨) and a greatest lower bound (meet, ∧). Special cases: bounded, distributive, complemented, Boolean.

Key points

Poset
Reflexive + antisymmetric + transitive. Incomparable elements form antichains; totally ordered subsets are chains.
Join & meet
a ∨ b = least upper bound; a ∧ b = greatest lower bound. A lattice has both for every pair; a complete lattice for every subset.
Hasse diagram
Draws only the covering relation upward — reflexive and transitive edges omitted. It fully determines a finite poset.
Examples
(P(S), ⊆): join = ∪, meet = ∩. (ℤ⁺, |): join = lcm, meet = gcd. Every chain is a distributive lattice (join = max, meet = min).
Distributive / Boolean
Distributive: a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c). Boolean = complemented + distributive. M₃ and N₅ are the forbidden sublattices for distributivity.

Example

                /  \             a ∧ b = gcd(a, b)
               4    6            2 ∨ 3 = 6,  2 ∧ 3 = 1

               2      3          D_12 is a distributive lattice
                \    /
                  1

D_30 = divisors of 30 (= 2·3·5, squarefree) ≅ the Boolean lattice B_3.
Common exam traps

A poset can have many MAXIMAL elements but at most one GREATEST element. Meet of the empty set = top; join of the empty set = bottom. (ℤ⁺, |) has a bottom (1) but no top. Every distributive lattice is modular, not vice versa. A finite lattice is distributive iff it has no M₃ or N₅ sublattice.

Practice MCQs

Q1. A partially ordered set has a relation that is:

  1. reflexive, symmetric, transitive
  2. reflexive, antisymmetric, transitive
  3. irreflexive, transitive
  4. total
Show answer

Answer: B. Some pairs may be incomparable.

Q2. A LATTICE is a poset in which:

  1. every element is maximal
  2. every pair of elements has both a join and a meet
  3. there are no incomparable elements
  4. every subset has a join
Show answer

Answer: B. A complete lattice: every subset has a join and meet.

Q3. In (ℤ⁺, |) ordered by divisibility, a ∨ b is:

  1. gcd(a, b)
  2. lcm(a, b)
  3. a + b
  4. a · b
Show answer

Answer: B. Join = lcm, meet = gcd.

Q4. A lattice is DISTRIBUTIVE if:

  1. a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c) for all a, b, c
  2. it has a top and bottom
  3. it is a chain
  4. every element has a complement
Show answer

Answer: A. M₃ and N₅ are the forbidden sublattices.

Q5. A BOOLEAN algebra is:

  1. any lattice
  2. a complemented distributive lattice
  3. a chain
  4. a poset with no top
Show answer

Answer: B. (P(S), ⊆) is the canonical example.
