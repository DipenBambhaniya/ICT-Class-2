Asymptotic Notation

Big-O, Omega and Theta describe how a function grows for large n, dropping constants and lower-order terms so algorithms can be compared by scalability alone.

Key points

O(g) — upper bound
f(n) ≤ c·g(n) for some c and all n ≥ n₀. 'Grows no faster than g'.
Ω(g) — lower bound
f(n) ≥ c·g(n). 'Grows at least as fast as g'.
Θ(g) — tight bound
Both O(g) and Ω(g). The exact order of growth.
little-o / little-ω
Strict versions: f/g → 0 (o) or f/g → ∞ (ω).
Rules
Constants and log bases drop; the dominant term wins; O is transitive; only Θ is symmetric.

Diagram

Example

3n² + 5n + 2      = Θ(n²)        // drop 5n, 2, and the 3
log₂ n vs log₁₀ n = same Θ       // bases differ by a constant factor
n log n vs n^1.01 = n^1.01 wins  // any positive power of n beats a polylog
2^n vs 2^(n/2)    = 2^n much bigger  // exponents are NOT constant factors
2^(2n) = 4^n     ≠ Θ(2^n)
Common exam traps

'Quicksort's worst case is O(n log n)' is wrong — the tight worst case is Θ(n²). log(n!) = Θ(n log n) (Stirling). n^(1/log n) is a constant. e^n is NOT O(2^n) since e > 2. Dropping the log base is valid; dropping an exponent is not.

Practice MCQs

Q1. f(n) = O(g(n)) means:

  1. f grows exactly like g
  2. f grows no faster than g (upper bound)
  3. f grows at least as fast as g
  4. f = g for all n
Show answer

Answer: B. There exist c, n0 with f(n) <= c g(n) for n >= n0.

Q2. 3n^2 + 5n + 2 is:

  1. O(n)
  2. Theta(n^2)
  3. Theta(n^3)
  4. O(log n)
Show answer

Answer: B. Drop constants and lower-order terms.

Q3. log(n!) is:

  1. Theta(n)
  2. Theta(n log n)
  3. Theta(n^2)
  4. Theta(log n)
Show answer

Answer: B. By Stirling's approximation.

Q4. Is n^3 = O(n^2)?

  1. yes
  2. no
  3. yes, with a large constant
  4. only asymptotically
Show answer

Answer: B. No constant c makes n^3 <= c n^2 for all large n.

Q5. log base a vs log base b (a,b>1):

  1. different orders of growth
  2. differ only by a constant factor (same Theta)
  3. one is O of the other only
  4. incomparable
Show answer

Answer: B. log_a n = log_b n / log_b a.
