OLAP

Online Analytical Processing supports fast, interactive, multidimensional exploration of large historical datasets — sliced, diced, drilled into, and rolled up across dimensions like Time, Product, and Region.

Key points

Core operations
Slice (fix one dimension), Dice (filter across several), Drill-down (more detail), Roll-up (more summary), Pivot (reorient the view).
Dimensions & measures
Dimensions are the "by what" (Time, Product, Region); measures are the numeric values analyzed (sales, quantity).
MOLAP / ROLAP / HOLAP
MOLAP pre-computes cubes for speed. ROLAP queries relational tables via SQL for scalability. HOLAP blends both.
Hierarchies
A dimension's levels (Day → Month → Quarter → Year) let drill-down/roll-up navigate between granularities.
FASMI test
Fast, Analysis, Shared, Multidimensional, Information — a commonly cited criteria set for genuine OLAP capability.

Diagram

Example

Starting view: Total Sales by Region (Year 2024)
  East: 450K   West: 380K   North: 210K   South: 300K

DRILL-DOWN into East by Month:
  Jan: 32K  Feb: 35K  ...  Dec: 41K   (sum = 450K)

ROLL-UP back to Country level:
  All Regions combined: 1,340K

PIVOT: swap so Months become columns, Regions become rows
  (same data, different cross-tab orientation)
Common exam traps

Slice fixes ONE dimension value; dice filters across MULTIPLE dimensions. Drill-down = more detail; roll-up = more summary — don't reverse them. MOLAP is fast but storage/processing heavy; ROLAP scales better but needs more joins at query time. Pivot only rearranges the VIEW — it never changes the underlying data.

Practice MCQs

Q1. OLAP stands for:

  1. Online Application Processing
  2. Online Analytical Processing
  3. Offline Analytical Programming
  4. Online Algorithmic Processing
Show answer

Answer: B. Designed for complex analytical queries over large historical datasets.

Q2. The "drill-down" operation means:

  1. Moving to a more summarized level
  2. Moving to a more detailed level
  3. Rotating the cube's axes
  4. Deleting data
Show answer

Answer: B. E.g. Year → Month reveals more granular detail.

Q3. MOLAP stores data:

  1. Only in relational tables
  2. In pre-computed, specialized multidimensional structures
  3. As flat text files
  4. In a document database
Show answer

Answer: B. Fast queries, but more storage/processing to build.

Q4. ROLAP works by:

  1. Never using SQL
  2. Storing data relationally and generating SQL dynamically for analysis
  3. Requiring a proprietary storage format
  4. Eliminating schema design
Show answer

Answer: B. Leverages existing relational technology; trades some speed for scalability.

Q5. An OLAP "measure" represents:

  1. A categorical grouping like Region
  2. The numeric value being analyzed, like sales amount
  3. A table name
  4. An index type
Show answer

Answer: B. Dimensions provide the "by what" context for measures.
