Combinatorics

Counting: the sum and product rules, permutations and combinations, the binomial theorem, inclusion-exclusion, stars and bars, then recurrence relations and generating functions for structured counting.

Key points

Basic counts
Permutations n!; k-permutations P(n,k) = n!/(n−k)!; combinations C(n,k) = n!/(k!(n−k)!). Σ_k C(n,k) = 2^n.
Stars & bars
Non-negative integer solutions to x₁+…+x_k = n: C(n+k−1, k−1). Same as multisets of size n from k types.
Inclusion-exclusion
|A₁ ∪ … ∪ A_n| = Σ|Aᵢ| − Σ|Aᵢ∩Aⱼ| + … Derangements D(n) = n! Σ (−1)^k/k! ≈ n!/e.
Recurrences
Linear homogeneous a_n = c₁a_{n−1}+c₂a_{n−2}: solve the characteristic equation x² = c₁x + c₂. Repeated root r ⇒ (A + Bn)rⁿ. Non-homogeneous = homogeneous + particular.
Generating functions
G(x) = Σ a_n xⁿ. 1/(1−x) ↔ (1,1,1,…); (1+x)ⁿ ↔ binomial coefficients; product ↔ convolution. Fibonacci GF: x/(1−x−x²).

Example

Non-negative solutions to  x₁ + x₂ + x₃ = 10:
  stars & bars: C(10 + 3 − 1, 3 − 1) = C(12, 2) = 66

Solve  a_n = 5a_{n−1} − 6a_{n−2},  a_0 = 0, a_1 = 1:
  characteristic  x² − 5x + 6 = 0  →  x = 2, 3
  a_n = A·2ⁿ + B·3ⁿ;  a_0 = A + B = 0,  a_1 = 2A + 3B = 1
  →  B = 1, A = −1   ⇒   a_n = 3ⁿ − 2ⁿ
Common exam traps

P(n,k) counts ORDERED selections, C(n,k) UNORDERED. Stars and bars is C(n+k−1, k−1), not C(n,k). A characteristic equation with a repeated root r needs the (A + Bn)rⁿ form. The Catalan number C_n = C(2n,n)/(n+1) counts binary trees, balanced parentheses and polygon triangulations. Derangements ≈ n!/e, not n!/2.

Practice MCQs

Q1. The number of ways to choose k objects from n (order irrelevant) is:

  1. n^k
  2. P(n, k) = n!/(n−k)!
  3. C(n, k) = n!/(k!(n−k)!)
  4. k^n
Show answer

Answer: C. The binomial coefficient.

Q2. The number of non-negative integer solutions to x₁+…+x_k = n (stars and bars) is:

  1. k^n
  2. C(n + k − 1, k − 1)
  3. n!/k!
  4. C(n, k)
Show answer

Answer: B. Equivalently, size-n multisets from k types.

Q3. The characteristic equation of a_n = c₁a_{n−1} + c₂a_{n−2} is:

  1. x = c₁ + c₂
  2. x² = c₁x + c₂
  3. a_n = 0
  4. x² + c₁x + c₂ = 0 with x = a_n
Show answer

Answer: B. Distinct roots ⇒ a_n = A r₁ⁿ + B r₂ⁿ.

Q4. The Catalan number C_n counts:

  1. permutations of n elements
  2. balanced parenthesis strings / binary trees with n nodes / polygon triangulations
  3. subsets of an n-set
  4. derangements
Show answer

Answer: B. C_n = C(2n, n)/(n + 1).

Q5. Multiplying two generating functions corresponds to which operation on sequences?

  1. term-by-term product
  2. convolution: c_n = Σ a_k b_{n−k}
  3. shift
  4. sum
Show answer

Answer: B. This is why GFs solve combined-choice counting problems.
